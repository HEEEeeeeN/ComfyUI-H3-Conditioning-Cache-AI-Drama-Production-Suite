# 分镜导演 Skill（Storyboard Director）

> 一个面向 **AI 动画短剧生产** 的分镜设计与审阅专长（Skill）。它将专业分镜方法论沉淀为可调用的知识库与标准流程，帮助 AI 从任意剧本/场景描述出发，设计出既符合叙事规律、又满足 AI 生成可行性的结构化分镜表与 H3 视频提示词。
>
> 本 Skill 沉淀自一部 AI 动画短剧项目的真实生产实践，已在实战中验证。公开版已去除未发布作品的敏感设定信息，保留可直接复用的完整方法论。

---

## 一、触发条件

当用户需要以下操作时触发本 Skill：

| 触发场景 | 用户意图 | 输出 |
|---------|---------|------|

| **审阅分镜** | "帮我看看这个分镜合不合格" / "审阅一下这个分镜表" / "检查分镜质量" | 审阅报告 |
| **优化分镜** | "这个分镜有问题，帮我改" / "优化这个分镜的节奏" / "调整景别序列" | 修改后的分镜表 |

## 三、设计分镜流程

```
Step 1: 确认需求
  ↓
Step 2: 调取项目素材
  ↓
Step 3: 剧本拆解
  ↓
Step 4: 镜头序列设计
  ↓
Step 5: 逐镜技术决策
  ↓
Step 6: 节奏与时长分配
  ↓
Step 7: 生成结构化分镜表
  ↓
Step 8: 生成提示词草稿
  ↓
Step 9: 生成分镜头需求 MD 文件
  ↓
Step 10: 自检
```

### Step 1：确认需求

| 确认项 | 内容 | 影响 |
|--------|------|------|
| 剧本来源 | 哪个剧本/场景描述 | 决定拆解对象 |
| 画幅 | 9:16竖屏 / 16:9横屏 / 2.35:1宽银幕 | 决定构图和景别偏好 |
| 时长 | 竖屏55-65秒 / 横屏120-150秒 | 决定镜头数和节奏 |
| 集数/片段 | 第X集 / 预告片 / 特别篇 | 决定叙事功能 |
| 线/场景 | 项目内设定（如 叙事线A / 叙事线B） | 决定色板和风格 |

### Step 2：调取项目素材

加载以下素材（必加载 `分镜风格规范.md`）：
- 角色视觉锚点（从 `分镜风格规范.md` 第二章）
- 场景视觉参考（从 `分镜风格规范.md` 第三章）
- 色板规范（从 `分镜风格规范.md` 第一章）
- 短剧铁律（如为竖屏短剧，加载 `短剧铁律.md`）

### Step 3：剧本拆解

加载 `剧本拆解法.md`，执行5步拆解：

1. **通读识别戏剧要素**：主角目标/障碍/转折点/情感弧光/主题表达
2. **按场景切分**：同一时间+地点+人物的连续段落为一个场景
3. **提取视觉关键信息**：四问框架（有什么/发生什么/相机在哪/持续多久）
4. **明确展示与暗示**：什么直接呈现、什么用视觉线索暗示
5. **输出分镜设计依据**：场景信息卡 + 视觉关键信息 + 镜头序列初步规划

### Step 4：镜头序列设计

加载 `镜头序列设计法.md` + `镜头衔接逻辑.md`，执行：

1. **轴线原则**：标注对话轴线/运动轴线/视线轴线，确保无跳轴
2. **正反打设计**：对话场景设计OTS或特写交替结构；**对白超过 5 秒的段落必须在此步拆成正反打序列**（正反打既是空间建立手段，也是长镜头拆分工具，详见 Step 6.1）
3. **景别节奏规划**：避免连续3个同级，设计渐紧/渐松模式
4. **高潮与铺垫分配**：设计情绪曲线（铺垫→升级→高潮→释放）
5. **镜头衔接逻辑**：为每对相邻镜头标注衔接类型
6. **AI成功率匹配**：标注每镜AI成功率，低成功率镜头提供替代方案

### Step 5：逐镜技术决策

加载 `景别光谱.md` + `机位角度系统.md` + `运镜类型系统.md` + `构图法则库.md` + `转场类型库.md`，为每个镜头填写：

| 决策项 | 参考文件 | 决策依据 |
|--------|---------|----------|
| 景别 | 景别光谱.md | 叙事功能 + 节奏作用 + AI成功率 |
| 机位角度 | 机位角度系统.md | 心理暗示 + 适用场景 |
| 运镜 | 运镜类型系统.md | 叙事功能 + AI生成难度 |
| 构图 | 构图法则库.md | 视觉目标 + 情绪表达 |
| 转场 | 转场类型库.md | 时空关系 + 使用频率 |
| 情绪匹配 | 情绪镜头对应表.md | 场景情绪 → 镜头参数 |

#### 5.1 官方镜头质量增强（必加载 `07_官方分镜方法论/shot_table_design.md`）

在逐镜技术决策之上，按官方方法论补齐镜头连续性、空间锚点、Hook 与逐秒指令：

| 增强项 | 依据 | 说明 |
|--------|------|-------|
| 连续性衔接 | shot_table_design.md §2.2 | 每镜如何承接上一镜结束状态、如何为下一镜铺钩 |
| 空间锚点卡 | shot_table_design.md §2.3/§4 | 固定地标 + 人物位置 + 退场人物状态 + 光位基线，四子字段必填 |
| Hook 类型 | shot_table_design.md §2.4 | 从受控词表挑一标签，用于全片 hook 分布自检 |
| 每秒指令 | shot_table_design.md §2.5 | Per-Second Directives，每条覆盖动作/镜头/空间/音频/交接五要素 |
| 音频与对白轨 | shot_table_design.md §2.6 | 旁白/对白/音效按时间锚定 + 表演备注 |

> 本项目为 2D 写实系短剧，表演不追求官方 3D 动画的夸张弹性，但"连续性/锚点/逐秒覆盖"的**结构**必须保留，以保证 Ref2VA 提示词的锚点一致。

### Step 6：节奏与时长分配

加载 `节奏控制原则.md`，执行：

1. **总时长分配**：按段落/情绪阶段分配时长
2. **单镜时长（H3 甜点约束）**：H3 模型能力甜点为 **4-6 秒**，目标单镜时长 3-7 秒，**硬上限 8 秒**。情绪强度决定具体值（快1-2秒/中2-4秒/慢4-6秒），任何镜头超过 8 秒必须拆分（见 Step 6.1）。**严禁照搬剧本单场景时长作为单镜时长**——剧本里的一个"镜头"（如"金止戈演讲10秒"）在分镜阶段必须拆成多个 4-6 秒的短镜。
3. **节奏曲线**：设计铺垫→升级→高潮→释放的节奏变化
4. **音画同步**：标注声音内容、声音衔接方式、关键节拍切镜点

### Step 6.1：长镜头拆分法则（H3 能力甜点导向）

> **核心原则**：H3 单镜甜点 4-6 秒、硬上限 8 秒。剧本中的长段落（对话、动作、展示）**必须**按传统影视语言拆成短镜，而不是整段放进一个镜头。拆分不仅能控制生产时长，更能让画面在正反打、插入镜、反应镜的交替中保持信息密度与节奏感。

**拆分触发规则**：

| 触发条件 | 必须拆分 |
|---------|---------|
| 镜头估算 > 8 秒 | 硬上限，强制拆分 |
| 对白总时长 > 5 秒 | 拆成正反打交替（见下） |
| 连续动作含 2 个以上节拍 | 按动作节拍拆 |
| 既有全景展示又有细节信息 | 拆成全景 + 特写插入 |

**拆分工具箱（传统影视技能）**：

| 工具 | 用法 | 典型时长 |
|------|------|---------|
| **正反打** | 两人对话：A 说（OTS/特写）→ B 反应（特写）→ B 回话（OTS）→ A 反应 | 每切 1.5-3 秒 |
| **插入镜 / Insert** | 对话中插入道具、手部、信件等细节特写，打断长对白 | 1-2 秒 |
| **反应镜 / Reaction** | 台词说完后切听者反应，强化情感节拍 | 1.5-2 秒 |
| **景别递进** | 全景→中景→特写逐级收紧，把长展示拆成 3 个短镜 | 每镜 2-3 秒 |
| **动作节拍拆分** | 起手→关键动作→结果/反应，各取一镜 | 每镜 1.5-3 秒 |
| **进出画拆分** | 动作从入画到出画拆成多镜，保留运动轴线 | 每镜 2-3 秒 |

**对话拆分模板**（对白 > 5 秒时必用）：

```
原始（照搬剧本，错误）：
  镜A（10秒）：A 说一整段台词，B 站着听
拆分后（正确）：
  镜A1（2.5秒）：OTS A→B，A 说第一句（<d>[Chinese][男] 台词1</d>）
  镜A2（2秒）：B 的反应特写，A 台词画外继续（<d>[Chinese][男] 台词2</d> 画外音）
  镜A3（2.5秒）：OTS B→A，A 说关键句（<d>[Chinese][男] 台词3</d>）
  镜A4（2秒）：A 表情特写 + 插入镜（道具/环境细节）
  镜A5（1.5秒）：B 反应/动作，段落收束
```

**拆对白规则（拆镜必须先拆句）**：长台词本身也要拆，不能整句塞进一个镜头画外音带过。

| 规则 | 标准 |
|------|------|
| 单句时长上限 | 一句台词朗读时长 ≤ 3-4 秒（中文 ≤15 字 / 日文 ≤15 假名 / 韩文 ≤15 音节 / 英文 ≤10 词） |
| 超限必拆 | 单句超限 → 按语义单元拆成 2 句以上，每句一个完整信息单元 |
| 拆句位置 | 标点处（逗号/句号/省略号）、语气转折、主谓宾完整处；禁止生硬腰斩 |
| 每镜对白量 | 每镜最多 1 句核心台词（画外音承接可 +1 句），多句台词拆到多个镜头 |
| 拆句锚定 | 拆出的每句独立锚定到对应镜头的【两级时间轴】，说话人 ID 保持一致 |
| 完整性 | 拆句后台词总内容与原文一致，不得删减信息；语序保持自然 |

**动作拆分模板**（连续动作 > 8 秒时必用）：

```
原始（照搬剧本，错误）：
  镜B（12秒）：金止戈从掩体后起身、端枪、扫视、奔向下一掩体
拆分后（正确）：
  镜B1（2秒）：全景，金止戈在掩体后探头观察（铺垫）
  镜B2（2秒）：特写，手部握枪、指节发力（细节）
  镜B3（2.5秒）：中景，起身端枪，枪口指向画面右（动作起始）
  镜B4（2.5秒）：跟随，冲出掩体奔向下一掩体（动作主体）
  镜B5（2秒）：特写，落地卧倒、回头警戒（动作收束/反应）
```

**拆分纪律**：
1. 每个拆分后的镜头只承载**一个核心戏剧动作**或**一句核心对白**
2. 拆分后的镜头必须满足 30 度规则与轴线规则（同侧景别相邻镜头角度变化 ≥30 度，正反打不越轴）
3. 拆分后为每对相邻镜头标注衔接逻辑（动作/视线/因果，见 `镜头衔接逻辑.md`）
4. 拆分会增加镜头数，属正常现象；分镜总时长与剧本段落时长一致，**镜头数增多不等于时长膨胀**
5. 拆分后的短镜同样输出完整 10 字段分镜表与完整 H3 提示词（每镜一条）

### Step 7：生成结构化分镜表

加载 `标准分镜表模板.md`，按模板输出：
- 竖屏短剧 → 使用9:16竖屏模板
- 横屏长片 → 使用16:9横屏模板

每个镜头必须包含10项标准字段：
1. 镜头号 2. 时长 3. 景别 4. 机位角度 5. 运镜 6. 构图 7. 画面内容 8. 人物动作 9. 声音 10. 转场

在 10 字段之外，按 `07_官方分镜方法论/shot_table_design.md` 为每镜补充**空间锚点卡**（固定地标/人物位置/退场人物状态/光位基线）与**连续性**（承接 S(N-1)/交接 S(N+1)），确保跨镜空间与身份一致，为 Ref2VA 提示词提供锚点基础。

### Step 8：生成 H3 视频提示词

**必加载**：`06_H3提示词指南/提示词规范格式.txt`（提示词输出规范，最高优先级）+ `07_官方分镜方法论/h3_prompt_workflow.md`（识别模式与镜头语法）+ `06_H3提示词指南/h3_base_prompt_guide.md`（英文措辞参考，如为全参考模式则同时加载 `h3_ref_prompt_guide.md`）。

**输出骨架**：「完整提示词」一律按 `提示词规范格式.txt` 的九个分节输出，顺序固定、逐节完整填充：`【输出规格】→【参考图约束】→【整体风格】→【场景描述】→【两级时间轴】→【摄影与摄像机】→【光影】→【声音】→【约束条件】`。禁止省略分节、禁止压缩为一段话、禁止改用 H3 官方英文三字段骨架。

#### 8.1 选择提示词模式

| 模式 | 适用场景 | 参考图需求 |
|------|---------|------------|
| T2VA | 纯文本生成，无参考图 | 无 |
| I2VA | 首帧驱动 | 1张首帧图 |
| FL2VA | 首尾帧驱动 | 2张关键帧 |
| L2VA | 末帧驱动 | 1张末帧图 |
| Ref2VA | 全参考模式 | 角色+场景+道具参考图 |

本项目通常使用 **Ref2VA** 模式（角色定妆照 + 场景参考图驱动）。

#### 8.2 按九分节规范逐节填充完整提示词

**本步输出的是「完整提示词」九分节全文，不是 H3 官方英文三字段。** 严格按 `06_H3提示词指南/提示词规范格式.txt` 的九个分节，顺序固定、逐节完整填充：

| 分节 | 填充内容 | 强制规则 |
|------|---------|---------|
| 【输出规格】 | 画幅、时长、生成模式（I2VA/Ref2VA 等） | 时长与分镜表一致 |
| 【参考图约束】 | 以输入的哪些参考图为基准，保持哪些属性完全一致，初始位置/姿态从参考图状态开始 | 引用 `<图片N>` 与槽位一致；逐镜写明"不得身份漂移" |
| 【整体风格】 | **项目画风句 + 风格基调** | **必须逐镜注入项目固定画风句**（Step 2 画风锁定确认的那句），不得省略、不得换成其他泛化风格描述 |
| 【场景描述】 | 场景空间、物体布局、环境光线的完整描写 | 与分镜表场景一致 |
| 【两级时间轴】 | 镜头N｜起止秒｜时长：逐段动作/光影/事件变化 + **对白锚定** | 逐秒或按关键节点分段，覆盖全时长；**对白必须按时间锚定写在此分节**（谁在哪个时间点说什么，按 8.5 对白格式） |
| 【摄影与摄像机】 | 景别、镜头运动（类型+幅度+速度）、焦点 | 按 8.4 摄影机运动规范写 |
| 【光影】 | 主光源、环境光、特殊效果、受光区域 | 按项目色板与场景光线写 |
| 【声音】 | **仅音效**：环境音、物理动作声、非语言人声、非叙事音乐 | **禁止写入对白**；对白一律写进【两级时间轴】；无配乐时写 `非叙事音乐：无` |
| 【约束条件】 | 外观一致性、物理规律、特效呈现、画幅时长等 | 与参考图约束呼应 |

**画风句注入铁律**：每个镜头完整提示词的【整体风格】分节必须写入项目固定画风句（Step 2 从画风锁定规范确认的 H3 固定画风句），全片各镜画风句一字不差；禁止只写"电影感/写实"等泛化风格而漏掉画风句。

#### 8.3 提示词要素中英双文标注

每个镜头的提示词要素以中英双文标注，供审阅表提取：

| 要素 | 中文 | English |
|------|------|---------|
| 镜头风格 | 电影感，实拍 | Cinematic, live-action |
| 场景 | 废弃水泥建筑内部 | Abandoned concrete building interior |
| 镜头调度 | 镜头缓慢推进，小幅度 | The camera pushes in with small amplitude at slow speed |
| 约束条件 | 角色一致性锚定 | Character consistency anchoring |

#### 8.4 摄影机运动规范（写入九分节【摄影与摄像机】分节）

按 H3 官方指南的三维度表达摄影机运动（运动类型 + 幅度 + 速度），写为自然动作描述：

```
The camera pushes in with small amplitude at slow speed toward the folded letter.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

可用运动类型：Zoom In/Out, Push In/Pull Out, Pan Left/Right, Truck Left/Right, Tilt Up/Down, Pedestal Up/Down, Arc Shot, Tracking Shot, Static Shot, Shake, POV, Roll。在九分节【摄影与摄像机】分节中直接用中文或中英双语表达即可（如"景别：中景；镜头：缓慢推近，小幅度"）。

#### 8.5 对白格式与语言标注（写入九分节【两级时间轴】分节）

对白写入九分节【两级时间轴】分节，**禁止写入【声音】分节**（【声音】只处理音效）。使用稳定说话人 ID `(S1·男)`、`(S2·女)`（**ID 必须带性别标记**），对白用 `<d>[语言][性别] 内容</d>` 包裹（语言标签与台词原文保持剧本原样，不翻译；性别标签标注说话人性别），并按时间锚定：

```
- 1.5-3.0：通讯兵（S5·男，立正）报告：<d>[Chinese][男] 报告。韩军呼叫，要求炮击金山町通讯站。</d>
- 3.0-4.5：军官（S7·男，头也不抬，平淡）：<d>[Chinese][男] 韩国人指挥起我们来了？</d>
```

画外音用 `says in an off-screen voiceover`（或中文"画外音"），并标注嘴唇保持闭合。

**【声音】分节只写音效**：环境音（风声/枪声/脚步声/机械声等）、物理动作声（非语言）、非叙事音乐。示例：`【声音】环境音：风声、远处枪声；非叙事音乐：无。`——不出现任何对白文本。

**台词语言标注规范**：

剧本中台词可能存在多种语言（原文、翻译、混用），分镜导演必须逐句检测台词语言并正确标注，确保下游 TTS 合成和提示词审阅表能准确识别。

| 语言标签 | 适用场景 | 示例 |
|---------|---------|-------|
| `[Chinese]` | 中文台词（普通话） | `<d>[Chinese][男] 我下一站下车。</d>` |
| `[Japanese]` | 日语台词 | `<d>[Japanese][女] 次の駅で降ります。</d>` |
| `[English]` | 英语台词 | `<d>[English][男] I get off at the next station.</d>` |
| `[Korean]` | 韩语台词 | `<d>[Korean][女] 다음 역에서 내립니다.</d>` |
| `[Mixed]` | 同一句中混用两种以上语言 | `<d>[Mixed][男] 好的, thank you very much.</d>` |
| `[Silent]` | 无台词，仅有语气词/呼吸声 | `<d>[Silent][男] (heavy breathing)</d>` |

**语言检测规则**：
1. **优先检测剧本原文语言**：若剧本为中文，台词默认标注 `[Chinese]`；若剧本为日文，默认 `[Japanese]`
2. **翻译剧本**：若剧本是翻译版（如日文原作译为中文），台词应标注**实际配音语言**，而非原文语言。例如中文配音的日本动画，台词标注 `[Chinese]`
3. **混用台词**：同一句中包含两种以上语言时标注 `[Mixed]`，并在 TTS 指引中注明主语言
4. **语气词**：纯语气词（"啊"、"嗯"、"ふん"）按所在语言的台词标注，不单独拆出
5. **一致性**：同一角色在不同镜头中的语言标签必须一致；若角色切换语言（如双语角色），在镜头要素中注明 "S1 switches to [English]"

**性别标注规范（防止音色错配）**：

模型按台词生成配音时，若说话人性别不明，会把女角色配成男声（或反之）。因此**每一句对白必须同时标注说话人性别**，说话人 ID 与 `<d>` 标签两处都要带：

| 标注位置 | 格式 | 示例 |
|---------|------|------|
| 说话人 ID | `(S1·男)` / `(S2·女)` | `军官（S7·男，头也不抬）` |
| `<d>` 标签 | `<d>[语言][性别] 内容</d>` | `<d>[Chinese][男] 韩国人指挥起我们来了？</d>` |

**性别标注规则**：
1. **性别以角色设定为准**：按角色性别标注 `[男]` 或 `[女]`，不按演员/配音演员性别，也不按说话内容推断
2. **两处必须一致**：说话人 ID 与 `<d>` 标签的性别必须一致，防止模型读到冲突信息
3. **画外音同样标注**：画外音（off-screen voiceover）的 `<d>` 标签同样带性别，如 `<d>[Chinese][女] 内容</d>`
4. **语气词/呼吸声**：`[Silent]` 类无台词也标注性别，如 `<d>[Silent][男] (heavy breathing)</d>`，供音色选择
5. **群杂/多人**：多人同时说话用 `[群杂]` 或分别标注各说话人 ID 与性别，禁止无性别裸标
6. **性别标签缺省视为格式错误**：对白 `<d>` 标签缺少 `[男]`/`[女]` 时，视为格式错误，需补全后再生成分镜

**在分镜头需求 MD 中的体现**：

每镜头的"完整 H3 提示词"中，所有对白必须写入【两级时间轴】分节，使用 `<d>[语言] 内容</d>` 格式并按时间锚定。例如：

```
【两级时间轴】镜头2｜0:00-6.0｜时长6.0秒：0:00-1.0 通讯兵掀帘入内，立正；1.0-2.5 通讯兵（S5·男，立正）报告：<d>[Chinese][男] 报告。韩军呼叫，要求炮击金山町通讯站。</d>；2.5-4.0 军官（S7·男，头也不抬）回话：<d>[Chinese][男] 韩国人指挥起我们来了？</d>
【声音】环境音：煤油灯哔啵声、纸张翻动声；非叙事音乐：无。
```

**下游衔接**：
- `shot_md_to_excel.py` 生成 Excel 时，自动检测 `<d></d>` 标记，将台词部分以红色字体显示，便于审阅
- TTS 合成时，根据 `[语言]` 标签选择对应的语音模型
- 若发现台词缺少语言标签，视为格式错误，需补全后再生成分镜

#### 8.6 对白时长估算（确定镜头时长）

**镜头时长必须先按对白长度核算，再叠加动作/情绪时长，取大者**，禁止不看对白直接拍脑袋定时长。估算基准（语速）：

| 语言 | 朗读语速基准 | 含标点停顿系数 |
|------|------------|---------------|
| 中文 | 约 4-5 字/秒 | ×1.2 |
| 日文 | 约 4-5 假名/秒 | ×1.2 |
| 韩文 | 约 4-5 音节/秒 | ×1.2 |
| 英文 | 约 3-4 词/秒 | ×1.2 |

**估算公式**：`对白所需秒数 = ceil(台词字符数 / 语速基准 × 1.2)`。

**镜头总时长规则**：
1. 逐句对白按 8.6 公式算各自时长，各句时长相加 = 对白总时长
2. 对白总时长 + 动作/反应预留（至少 0.5-1 秒/镜） = 镜头最短时长
3. 若动作/情绪需要更长（如慢镜、沉思），以动作时长为准
4. **H3 甜点拆镜判定（硬规则）**：最终镜头时长 > 8 秒 → 必须按 Step 6.1 拆分；对白总时长 > 5 秒 → 必须拆成正反打/插入镜交替（每句对白最多承载 3-5 秒，多句对白拆到多个镜头）。**禁止把"对白总时长 + 动作预留"直接当单镜时长**——超 5 秒的对白先在 Step 6.1 拆镜，再逐镜核算时长
5. 最终镜头时长 = max(对白时长 + 动作预留, 动作/情绪所需时长)，并按 H3 甜点自检门 ≤8 秒上限检查
6. 【两级时间轴】中的对白锚定时间点必须与镜头时长一致，对白结束时间不得超过镜头总时长

### Step 9：生成分镜头需求 MD 文件

将分镜表与 H3 提示词合并输出为**分镜头需求 MD 文件**（格式规范见第十二章），包含：
- 全局信息（画幅、总时长、镜头数、风格基调）
- 逐镜头信息（基本信息 + H3 提示词要素 + 完整 H3 提示词 + 美术资产需求）
- 中英双文标注

此 MD 文件是下游 Python 工具链的输入：`shot_md_to_excel.py` 读取后生成提示词审阅表 Excel。

### Step 10：自检

加载 `分镜评审Checklist.md` + `AI动画特殊检查项.md`，执行20项自检：

- 维度1 叙事逻辑（4项）：序列连贯/景别跳跃/无跳轴/衔接逻辑
- 维度2 视觉设计（4项）：技术参数/光影色调/角色表演/转场统一
- 维度3 节奏控制（4项）：时长/景别变化/高潮铺垫/音画同步
- 维度4 技术规范（3项）：10字段齐全/转场标注/角色锚点
- 维度5 AI约束（5项）：跨镜一致性/锚定策略/成功率/运动预埋/负面提示词

完成后，加载 `07_官方分镜方法论/shot_table_design.md` §3 执行**镜头表自检门（7项强制）**：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | Hook 密度 | 每镜有 Hook 类型；每连续 3 镜至少 1 镜用 reveal/reversal/callback；首尾镜各带强 hook |
| 2 | 单镜时长（H3 甜点） | 任何镜头 ≤8 秒，目标 4-6 秒；更长必须已按 Step 6.1 拆分 |
| 3 | 长镜头拆分 | 无 >8 秒镜头；无"一段长对白/长动作整段放一镜"；拆分后每镜仅一个核心动作/一句核心对白 |
| 4 | 单镜角色数 | 任何镜头 ≤3 个重要角色 |
| 5 | 空间锚点继承 | 同场景跨镜固定地标与光位基线一致或含明确连续性备注 |
| 6 | 每秒指令覆盖 | 0s 到镜尾逐秒有 5 要素指令，无时间空隙 |
| 7 | 跨镜连续性 | 连续性衔接列成连续链；翻转处明确标记 |

七项全过则戳 `shot-table self-check: passed`；任一不通过，返回 Step 5 修订后重跑。

## 五、AI动画分镜特殊约束

> 这是AI动画分镜与传统分镜的核心差异，设计/审阅时必须关注。

### 5.1 五大核心约束

| 约束 | 说明 | 检查方法 |
|------|------|---------|
| **锚定镜头策略** | 每场景第一个镜头定义角色外观和场景基调，后续镜头以此为参考 | 检查是否标注锚定镜和参考关系 |
| **跨镜角色一致性** | 同一角色在所有镜头中使用完全相同的锚点描述 | 对比所有镜头的角色描述 |
| **镜头成功率匹配** | 优先使用高成功率类型，低成功率有替代方案 | 对照AI成功率表检查 |
| **运动方向预埋** | 静态画面中预埋运动方向信息，为视频生成预留 | 检查备注栏运动预埋标注 |
| **负面提示词配置** | 通用+场景专属+角色专属负面提示词 | 检查提示词草稿完整性 |

### 5.2 锚定镜头选择标准

锚定镜头必须满足：
- 景别：LS/MS/FS（完整展示角色）
- 角度：平视/低角度（最稳定）
- 运镜：固定/慢推（最简单）
- 人物数：1人（最多2人）
- AI成功率：高

### 5.3 低成功率镜头规避策略

| 低成功率类型 | 规避策略 |
|------------|---------|
| 4+人群戏 | 拆分为单人/双人镜头，或用剪影/前后景虚化 |
| 快动作 | 用慢动作/关键帧/结果呈现法 |
| 精确连续性 | 降低连续性要求，用闪白/音效过渡 |
| 复杂运镜 | 拆分为单运镜，复杂效果后期实现 |
| 手部特写 | 用遮盖/替代物件/大特写 |

## 六、项目风格约束

> 详细规范框架见 `分镜风格规范.md`，以下为核心要点。公开版中角色与场景示例已匿名化，实际使用时请替换为自有项目的锚点。

### 6.1 色板约束

设计分镜时，为每个叙事线定义主色/点缀色/禁止色，并遵守"关键颜色语义"：

- 主色用于表意与氛围，点缀色用于符号与情感焦点，禁止色避免出戏。
- 关键原则示例：纯黑只用于最严肃的符号；暖光永远出现在"有人在的地方"；血液用干涸暗褐而非鲜红。

### 6.2 角色锚点规则

- 每个镜头使用**完整锚点描述**（发型+发色+五官+体型+服装+道具）
- **禁用代词**（"她""他"）
- 跨镜头锚点**一字不差**
- 标志性道具不遗漏

### 6.3 视觉母题

| 母题 | 用途 | 分镜处理 |
|------|------|---------|
| 核心信物 | 角色的信念/约定 | 特写→匹配切到象征物 |
| 失武器 | 失去战斗力/被缴械 | 视线匹配特写，不解释 |
| 图腾符号 | 阵营/信念 | 纯黑，只在关键镜头出现 |
| 生命暖光 | 有人在的地方/生命 | 与冷灰基调形成对比 |
| 手绘痕迹 | 记忆/人的痕迹 | 越重要越用力，线条歪扭 |
| 灵体 | 悬念身份 | 前期不解释身份，留悬念 |

## 七、竖屏短剧特殊规范

> 详细规范见 `短剧铁律.md`，以下为核心要点。

### 7.1 七条铁律

1. **3秒钩子**：开头必须有冲突或悬念
2. **50-70秒一集**：6-8个镜头
3. **竖屏优先**：近景+特写为主
4. **每集一次反转**：中间有出人意料的转折
5. **结尾死钩子**：最后一秒逼观众点下一集
6. **情绪大于信息**：不灌输世界观，制造情绪
7. **AI全链路**：角色一致性是核心挑战

### 7.2 标准7镜结构

```
镜1（3秒）· 钩子 → 冲突/悬念/视觉冲击
镜2（5-7秒）· 铺垫/闪回 → 快速交代前因
镜3（8-10秒）· 反转/转机 → 局势改变
镜4（8-12秒）· 核心/对话 → 最重要的对话
镜5（5-6秒）· 行动/变化 → 角色行动
镜6（5-7秒）· 追问/揭示 → 身份揭示
镜7（5-6秒）· 死钩子 → 悬念/信息冲击
```

## 十二、分镜头需求 MD 格式规范

> 此格式是分镜导演 Skill 的最终输出物，也是下游 Python 工具链（`shot_md_to_excel.py`）的输入。必须严格遵循以下结构，确保脚本可解析。

### 12.1 文件命名

`分镜头需求_第X集.md` 或 `分镜头需求_预告片.md`

### 12.2 完整格式

```markdown
# 分镜头需求表 - 第1集

## 全局信息
- 画幅: 16:9
- 总镜头数: 32
- 总时长: 156秒
- 风格基调: Cinematic, live-action / 电影感，实拍风格
- 提示词模式: Ref2VA

## 镜头列表

### A01
- **镜头名称**: 废墟猫叫
- **时长**: 5秒
- **景别**: 全景 / Wide Shot
- **机位角度**: 平视 / Eye-level
- **运镜**: 固定 / Static Shot
- **构图**: 三分法 / Rule of Thirds
- **转场**: 无（首镜）

#### H3 提示词要素
- **镜头风格 / Style**: Cinematic, live-action / 电影感，实拍
- **场景 / Scene**: Abandoned concrete building interior with dusty light beams / 废弃水泥建筑内部，浮尘光柱
- **镜头调度 / Camera**: The camera holds a static shot / 镜头保持固定
- **约束条件 / Constraints**: Character consistency anchoring, no axis jump / 角色一致性锚定，无跳轴

#### 完整 H3 提示词
【输出规格】生成一段5秒、16:9的测试视频。图生视频模式（I2VA）。
【参考图约束】以输入的猫咪图片为基准，严格保持该猫咪的品种、毛色、斑纹分布、瞳色、体态比例完全一致，不得产生身份漂移或外观变异。猫咪的初始位置和姿态以参考图中呈现的为准，从该状态开始运动。
【整体风格】写实电影质感，阴天柔光，东欧风格的废弃水泥建筑废墟，阴郁冷调中透出温暖光线。
【场景描述】一片废弃的水泥工厂废墟，地面散落着破碎的混凝土块、锈蚀的钢筋和积水洼。背景是坍塌的半截墙壁和框架结构，远处隐约可见灰绿色的苔藓附着在水泥表面。天空被厚重的灰白色云层覆盖，呈现典型的阴天漫射光环境。
【两级时间轴】镜头1｜0:00-5.0｜时长5.0秒：0:00-1.0 猫咪站在画面左侧一块较平整的水泥板上，静止状态，耳朵微微转动；1.0-2.5 猫咪开始向前迈步，先迈出右前爪，轻巧地落在一块较低的碎石上；2.5-3.5 光束穿过空气中悬浮的水泥粉尘和细微水雾，形成清晰可见的丁达尔光，光柱呈圆锥形散射，带有温暖的淡金色调；3.5-4.5 猫咪继续向前穿行约两步，绕过一块较大的混凝土碎块；4.5-5.0 猫咪走到画面中央偏右位置，停下脚步，低头嗅了嗅地面的一小片积水，形成电影感的结束构图。
【摄影与摄像机】景别：中景，猫咪占画面高度的约35%，保留充足的环境空间；镜头：缓慢跟随平移，从猫咪的左侧跟随至中央，速度平滑，与猫咪步行速度同步，无抖动；焦点：始终保持对猫咪的清晰对焦，背景废墟保持适度虚化但不完全模糊。
【光影】主光源：来自云层缝隙透出的自然天光，形成丁达尔光柱，色温偏暖（约3500K）；环境光：阴天漫射天光，色温偏冷（约6500K），占据画面90%区域；特殊效果：光束照射路径中需呈现悬浮微尘/水雾颗粒；猫咪受光区域：光束照射的背部区域产生暖色高光，未被照射的侧面保持阴天冷调，形成局部冷暖对比。
【声音】环境音：阴天微风吹过废墟的呼呼声，远处隐约传来零星水滴落下的回声；非叙事音乐：无。
【约束条件】严格保持猫咪的外观与参考图一致，不得出现毛色变化、斑纹移位、体型突变；猫咪运动必须符合物理规律，步态自然流畅；丁达尔光的光束必须呈现清晰的圆锥形光柱效果，空气中的悬浮颗粒可见；光束照射角度需与云层缝隙的合理位置一致；画面不出现文字、水印或突兀的剪辑痕迹；全程保持16:9画幅，5秒时长精确无误。

#### 美术资产需求
- **参演角色**: 主角A
- **场景参考**: 场景S01
- **道具参考**: (无)

---

### A02
- **镜头名称**: 对白示例·通讯兵报告 / Dialogue example
- **时长**: 6秒
- **景别**: 中景 / Medium Shot
- **机位角度**: 平视 / Eye-level
- **运镜**: 固定 / Static Shot
- **构图**: 框架（营帐门口）/ Framed by tent door
- **转场**: 硬切
- **对白时长核算**: 台词"报告。韩军呼叫，要求炮击金山町通讯站，射界不够，是否调动自动榴弹炮？"=23字 ÷ 4.5字/秒 × 1.2 ≈ 6.1秒 → 取 6秒；动作预留0.5秒 → 镜头时长=6秒

#### H3 提示词要素
- **镜头风格 / Style**: Cinematic, live-action / 电影感，实拍
- **场景 / Scene**: Command tent, folding table with maps / 指挥营帐，折叠桌地图
- **镜头调度 / Camera**: The camera holds a static shot / 镜头保持固定
- **约束条件 / Constraints**: Officer calmness / 军官沉稳

#### 完整 H3 提示词
【输出规格】生成一段6秒、16:9的横屏视频。全参考模式（Ref2VA）。
【参考图约束】以输入的角色参考图与营帐场景参考图为基准，保持外观一致；不得身份漂移。
【整体风格】硬朗战场剧情风格，去饱和的灰褐色与蓝黄色调，粗黑轮廓线赛璐璐上色，阴天战场光线穿过浮尘。
【场景描述】指挥营帐。折叠桌摊开军事地图，煤油灯燃着。通讯兵掀帘走进立正，军官（40岁，军装整齐）坐桌后看地图头也不抬。
【两级时间轴】镜头2｜0:00-6.0｜时长6.0秒：0:00-1.0 通讯兵掀帘入内，立正；1.0-2.5 通讯兵（S5·男，立正）报告：<d>[Chinese][男] 报告。韩军呼叫，要求炮击金山町通讯站，射界不够，是否调动自动榴弹炮？</d>；2.5-4.0 军官（S7·男，头也不抬）回话：<d>[Chinese][男] 韩国人指挥起我们来了？</d>；4.0-5.5 通讯兵（S5·男，一愣）：<d>[Chinese][男] ……是韩军前线请求支援。</d>；5.5-6.0 军官（S7·男，平淡）：<d>[Chinese][男] 叫他们自己搞定。</d>，继续看地图。
【摄影与摄像机】景别：中景；镜头：固定机位；焦点：军官清晰，门帘前景轻微虚化。
【光影】主光源：营帐灯暖光；环境光：灰褐天光；特殊效果：无；受光区域：军官面部半明半暗。
【声音】环境音：煤油灯哔啵声、地图纸张翻动声；非叙事音乐：无。
【约束条件】地图不生成可读文字；军官语气克制不轻浮；16:9画幅，6秒时长精确无误。
(同上格式)
```
