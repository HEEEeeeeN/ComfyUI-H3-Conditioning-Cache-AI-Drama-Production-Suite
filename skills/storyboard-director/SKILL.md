# 动画分镜导演 Skill（示例项目）

> **适用范围**：本项目所有分镜设计与审阅环节。从剧本/场景描述设计结构化分镜表，或审阅现有分镜是否合格。
>
> **职责边界**：本 Skill 只负责"剧本 → 结构化分镜表"。H3 提示词生成由独立 Skill `h3-prompt-writer` 承担。
>
> **与上下游的分工**：
> - 本 Skill 负责**上游**："剧本到手后，怎么设计分镜、怎么判断分镜合格"
> - `h3-prompt-writer` 负责**中游**："分镜表 → H3 九分节提示词 → 分镜头需求 MD"
> - `animation-production` 负责**下游执行层**："分镜确定后，怎么用AI生成画面"
> - 衔接点：本 Skill 输出的"结构化分镜表"→ `h3-prompt-writer` 逐镜生成 H3 提示词

## 三、设计分镜流程

```
Step 1: 确认需求
  ↓
Step 2: 调取项目素材
  ↓
Step 3: 剧本拆解
  ↓
Step 4: 镜头序列设计
  ↓
Step 5: 逐镜技术决策
  ↓
Step 6: 节奏与时长分配
  ↓
Step 7: 生成结构化分镜表
  ↓
Step 8: 自检
  ↓
输出结构化分镜表 → 移交 h3-prompt-writer 生成 H3 提示词
```

### Step 1：确认需求

| 确认项 | 内容 | 影响 |
|--------|------|------|
| 剧本来源 | 哪个剧本/场景描述 | 决定拆解对象 |
| 画幅 | 9:16竖屏 / 16:9横屏 / 2.35:1宽银幕 | 决定构图和景别偏好 |
| 时长 | 竖屏55-65秒 / 横屏120-150秒 | 决定镜头数和节奏 |
| 集数/片段 | 第X集 / 预告片 / 特别篇 | 决定叙事功能 |
| 线/场景 | b线 / d线 | 决定色板和风格 |

### Step 2：调取项目素材

加载以下素材（必加载 `分镜风格规范.md`）：
- **角色性别（必加载）**：`00_项目管理与协作规范/角色性别总表.md`——所有角色的性别唯一参考，分镜提示词中涉及角色时必须明确性别，防止美术生成和配音选型出现性别错误
- **镜头语言与站位（必加载）**：`00_项目管理与协作规范/镜头语言与站位规范.md`——剧本职责与分镜职责的边界；剧本只承载"站位自然描写 + 轻量【镜头意图】标注"，详细技术镜头语言（景别/机位/轴线/正反打执行/时长）由本 Skill 在此规范基础上设计
- **画风锁定（必加载）**：`07_美术与音频资源/画风锁定规范.md`（其他分线则加载 `美术风格指南.md`）——锚点图、画风触发词、H3固定画风句、色板
- 角色视觉锚点（从 `分镜风格规范.md` 第二章）
- 场景视觉参考（从 `分镜风格规范.md` 第三章）
- 色板规范（从 `分镜风格规范.md` 第一章）
- 短剧铁律（如为竖屏短剧，加载 `短剧铁律.md`）

> **画风锁定铁律**：分镜设计前必须先确认画风（锚点图+触发词+画风句），分镜头需求MD全局信息必须写入画风锚点段；不得单镜自行更换画风。
> **角色性别铁律**：分镜设计前必须确认所有出场角色性别；提示词中角色描述必须包含性别信息（如"young female soldier"而非模糊的"soldier"），防止下游美术生成性别错乱。
> **站位提取铁律**：剧本中的站位是自然描写（位置/朝向/视线），本 Skill 负责翻译为机位与构图；剧本的【镜头意图：手法——情绪】标注是"意图"，本 Skill 负责补齐执行参数（景别、机位角度、轴线、时长、正反打结构）。不得把技术参数回写进剧本文件（规范清洁）。

### Step 3：剧本拆解

加载 `剧本拆解法.md`，执行6步拆解：

1. **通读识别戏剧要素**：主角目标/障碍/转折点/情感弧光/主题表达
2. **按场景切分**：同一时间+地点+人物的连续段落为一个场景
3. **提取视觉关键信息**：四问框架（有什么/发生什么/相机在哪/持续多久）
4. **提取站位与镜头意图（必做）**：从剧本自然描写还原每场群戏的人物空间关系（位置/朝向/视线），据此推断轴线与机位候选；将剧本的【镜头意图：手法——情绪】标注登记为"意图卡"，作为后续镜头序列设计的输入（意图 → 手法执行，见 Step 4/6.1）
5. **明确展示与暗示**：什么直接呈现、什么用视觉线索暗示
6. **输出分镜设计依据**：场景信息卡 + 站位空间关系 + 视觉关键信息 + 镜头意图卡 + 镜头序列初步规划

### Step 4：镜头序列设计

加载 `镜头序列设计法.md` + `镜头衔接逻辑.md`，执行：

1. **轴线原则**：标注对话轴线/运动轴线/视线轴线，确保无跳轴
2. **正反打设计**：对话场景设计OTS或特写交替结构；**对白超过 5 秒的段落必须在此步拆成正反打序列**（正反打既是空间建立手段，也是长镜头拆分工具，详见 Step 6.1）
3. **景别节奏规划**：避免连续3个同级，设计渐紧/渐松模式
4. **高潮与铺垫分配**：设计情绪曲线（铺垫→升级→高潮→释放）
5. **镜头衔接逻辑**：为每对相邻镜头标注衔接类型
6. **AI成功率匹配**：标注每镜AI成功率，低成功率镜头提供替代方案

### Step 5：逐镜技术决策

加载 `景别光谱.md` + `机位角度系统.md` + `运镜类型系统.md` + `构图法则库.md` + `转场类型库.md`，为每个镜头填写：

| 决策项 | 参考文件 | 决策依据 |
|--------|---------|---------|
| 景别 | 景别光谱.md | 叙事功能 + 节奏作用 + AI成功率 |
| 机位角度 | 机位角度系统.md | 心理暗示 + 适用场景 |
| 运镜 | 运镜类型系统.md | 叙事功能 + AI生成难度 |
| 构图 | 构图法则库.md | 视觉目标 + 情绪表达 |
| 转场 | 转场类型库.md | 时空关系 + 使用频率 |
| 情绪匹配 | 情绪镜头对应表.md | 场景情绪 → 镜头参数 |

#### 5.1 官方镜头质量增强（必加载 `06_官方分镜方法论/shot_table_design.md`）

在逐镜技术决策之上，按官方方法论补齐镜头连续性、空间锚点、Hook 与逐秒指令：

| 增强项 | 依据 | 说明 |
|--------|------|------|
| 连续性衔接 | shot_table_design.md §2.2 | 每镜如何承接上一镜结束状态、如何为下一镜铺钩 |
| 空间锚点卡 | shot_table_design.md §2.3/§4 | 固定地标 + 人物位置 + 退场人物状态 + 光位基线，四子字段必填 |
| Hook 类型 | shot_table_design.md §2.4 | 从受控词表挑一标签，用于全片 hook 分布自检 |
| 每秒指令 | shot_table_design.md §2.5 | Per-Second Directives，每条覆盖动作/镜头/空间/音频/交接五要素 |
| 音频与对白轨 | shot_table_design.md §2.6 | 旁白/对白/音效按时间锚定 + 表演备注 |

> 本项目为 2D 写实系短剧，表演不追求官方 3D 动画的夸张弹性，但"连续性/锚点/逐秒覆盖"的**结构**必须保留，以保证 Ref2VA 提示词的锚点一致。

### Step 6：节奏与时长分配

加载 `节奏控制原则.md`，执行：

1. **总时长分配**：按段落/情绪阶段分配时长
2. **单镜时长（H3 甜点约束）**：H3 模型能力甜点为 **4-6 秒**，目标单镜时长 3-7 秒，**硬上限 8 秒**。情绪强度决定具体值（快1-2秒/中2-4秒/慢4-6秒），任何镜头超过 8 秒必须拆分（见 Step 6.1）。**严禁照搬剧本单场景时长作为单镜时长**——剧本里的一个"镜头"（如"主角演讲10秒"）在分镜阶段必须拆成多个 4-6 秒的短镜。
3. **节奏曲线**：设计铺垫→升级→高潮→释放的节奏变化
4. **音画同步**：标注声音内容、声音衔接方式、关键节拍切镜点
5. **对白时长标注（必做）**：按 `00_项目管理与协作规范/对白时长估算规范.md` 计算每镜对白秒数——语速基准（中文4字/秒、日语5假名/秒、韩语5音节/秒）+ 情绪系数；每句对白旁标注（约X秒）；**镜头时长 ≥ 对白总时长 × 1.25（余量给动作/反应）**；对白秒数 > 镜头时长则必须精简台词/拆分镜头/加长镜头，禁止"3秒镜头塞一大段台词"；**对白总时长 > 5 秒必须拆成正反打/插入镜交替（见 Step 6.1），禁止整段对白塞进一个镜头**

### Step 6.1：长镜头拆分法则（H3 能力甜点导向）

> **核心原则**：H3 单镜甜点 4-6 秒、硬上限 8 秒。剧本中的长段落（对话、动作、展示）**必须**按传统影视语言拆成短镜，而不是整段放进一个镜头。拆分不仅能控制生产时长，更能让画面在正反打、插入镜、反应镜的交替中保持信息密度与节奏感。

**拆分触发规则**：

| 触发条件 | 必须拆分 |
|---------|---------|
| 镜头估算 > 8 秒 | 硬上限，强制拆分 |
| 对白总时长 > 5 秒 | 拆成正反打交替（见下） |
| 连续动作含 2 个以上节拍 | 按动作节拍拆 |
| 既有全景展示又有细节信息 | 拆成全景 + 特写插入 |

**拆分工具箱（传统影视技能）**：

| 工具 | 用法 | 典型时长 |
|------|------|---------|
| **正反打** | 两人对话：A 说（OTS/特写）→ B 反应（特写）→ B 回话（OTS）→ A 反应 | 每切 1.5-3 秒 |
| **插入镜 / Insert** | 对话中插入道具、手部、信件等细节特写，打断长对白 | 1-2 秒 |
| **反应镜 / Reaction** | 台词说完后切听者反应，强化情感节拍 | 1.5-2 秒 |
| **景别递进** | 全景→中景→特写逐级收紧，把长展示拆成 3 个短镜 | 每镜 2-3 秒 |
| **动作节拍拆分** | 起手→关键动作→结果/反应，各取一镜 | 每镜 1.5-3 秒 |
| **进出画拆分** | 动作从入画到出画拆成多镜，保留运动轴线 | 每镜 2-3 秒 |

**对话拆分模板**（对白 > 5 秒时必用）：

```
原始（照搬剧本，错误）：
  镜A（10秒）：A 说一整段台词，B 站着听
拆分后（正确）：
  镜A1（2.5秒）：OTS A→B，A 说第一句（<d>台词1</d>）
  镜A2（2秒）：B 的反应特写，A 台词画外继续（<d>台词2</d> 画外音）
  镜A3（2.5秒）：OTS B→A，A 说关键句（<d>台词3</d>）
  镜A4（2秒）：A 表情特写 + 插入镜（道具/环境细节）
  镜A5（1.5秒）：B 反应/动作，段落收束
```

**拆对白规则（拆镜必须先拆句）**：长台词本身也要拆，不能整句塞进一个镜头画外音带过。

| 规则 | 标准 |
|------|------|
| 单句时长上限 | 一句台词朗读时长 ≤ 3-4 秒（中文 ≤15 字 / 日文 ≤15 假名 / 韩文 ≤15 音节 / 英文 ≤10 词） |
| 超限必拆 | 单句超限 → 按语义单元拆成 2 句以上，每句一个完整信息单元 |
| 拆句位置 | 标点处（逗号/句号/省略号）、语气转折、主谓宾完整处；禁止生硬腰斩 |
| 每镜对白量 | 每镜最多 1 句核心台词（画外音承接可 +1 句），多句台词拆到多个镜头 |
| 拆句锚定 | 拆出的每句独立锚定到对应镜头的【两级时间轴】，说话人 ID 保持一致 |
| 完整性 | 拆句后台词总内容与原文一致，不得删减信息；语序保持自然 |

**动作拆分模板**（连续动作 > 8 秒时必用）：

```
原始（照搬剧本，错误）：
  镜B（12秒）：主角从掩体后起身、端枪、扫视、奔向下一掩体
拆分后（正确）：
  镜B1（2秒）：全景，主角在掩体后探头观察（铺垫）
  镜B2（2秒）：特写，手部握枪、指节发力（细节）
  镜B3（2.5秒）：中景，起身端枪，枪口指向画面右（动作起始）
  镜B4（2.5秒）：跟随，冲出掩体奔向下一掩体（动作主体）
  镜B5（2秒）：特写，落地卧倒、回头警戒（动作收束/反应）
```

**拆分纪律**：
1. 每个拆分后的镜头只承载**一个核心戏剧动作**或**一句核心对白**
2. 拆分后的镜头必须满足 30 度规则与轴线规则（同侧景别相邻镜头角度变化 ≥30 度，正反打不越轴）
3. 拆分后为每对相邻镜头标注衔接逻辑（动作/视线/因果，见 `镜头衔接逻辑.md`）
4. 拆分会增加镜头数，属正常现象；分镜总时长与剧本段落时长一致，**镜头数增多不等于时长膨胀**
5. 拆分后的短镜同样输出完整 10 字段分镜表与完整 H3 提示词（每镜一条）

### Step 7：生成结构化分镜表

加载 `标准分镜表模板.md`，按模板输出：
- 竖屏短剧 → 使用9:16竖屏模板
- 横屏长片 → 使用16:9横屏模板

每个镜头必须包含10项标准字段：
1. 镜头号 2. 时长 3. 景别 4. 机位角度 5. 运镜 6. 构图 7. 画面内容 8. 人物动作 9. 声音 10. 转场

在 10 字段之外，按 `06_官方分镜方法论/shot_table_design.md` 为每镜补充**空间锚点卡**（固定地标/人物位置/退场人物状态/光位基线）与**连续性**（承接 S(N-1)/交接 S(N+1)），确保跨镜空间与身份一致，为 Ref2VA 提示词提供锚点基础。

> **人物位置指代明确铁律**：空间锚点卡的"人物位置"子字段必须用角色名指代（如"主角（坦克炮塔蹲坐剪影）"），禁止用"人影""一个人""那个人"等无主指代；剪影/剪影状态同样带角色名。无名群演/杂兵用身份称呼（如"我方通讯兵""敌方士兵"）。

### Step 8：自检

> **H3 提示词生成已拆分至独立 Skill `h3-prompt-writer`**。本 Skill 输出结构化分镜表后，由 `h3-prompt-writer` 接收分镜表，逐镜生成九分节 H3 提示词并输出分镜头需求 MD 文件。

加载 `分镜评审Checklist.md` + `AI动画特殊检查项.md`，执行20项自检：

- 维度1 叙事逻辑（4项）：序列连贯/景别跳跃/无跳轴/衔接逻辑
- 维度2 视觉设计（4项）：技术参数/光影色调/角色表演/转场统一
- 维度3 节奏控制（4项）：时长/景别变化/高潮铺垫/音画同步
- 维度4 技术规范（3项）：10字段齐全/转场标注/角色锚点
- 维度5 AI约束（5项）：跨镜一致性/锚定策略/成功率/运动预埋/负面提示词

完成后，加载 `06_官方分镜方法论/shot_table_design.md` §3 执行**镜头表自检门（8项强制）**：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | Hook 密度 | 每镜有 Hook 类型；每连续 3 镜至少 1 镜用 reveal/reversal/callback；首尾镜各带强 hook |
| 2 | 单镜时长（H3 甜点） | 任何镜头 ≤8 秒，目标 4-6 秒；更长必须已按 Step 6.1 拆分 |
| 3 | 长镜头拆分 | 无 >8 秒镜头；无"一段长对白/长动作整段放一镜"；拆分后每镜仅一个核心动作/一句核心对白 |
| 4 | 单镜角色数 | 任何镜头 ≤3 个重要角色 |
| 5 | 空间锚点继承 | 同场景跨镜固定地标与光位基线一致或含明确连续性备注 |
| 6 | 每秒指令覆盖 | 0s 到镜尾逐秒有 5 要素指令，无时间空隙 |
| 7 | 跨镜连续性 | 连续性衔接列成连续链；翻转处明确标记 |
| 8 | 指代明确 | 空间锚点卡人物位置与画面描述均用角色名，无"人影/一个人"等无主指代；剪影带角色名 |

八项全过则戳 `shot-table self-check: passed`；任一不通过，返回 Step 5 修订后重跑。

> **提示词格式自检**（`<d>` 性别、S 编号、`<图片N>` 引用等）已迁移至 `h3-prompt-writer` 的 Step 9 自检。

## 四、审阅分镜流程

```
Step 1: 接收待审分镜表
  ↓
Step 2: 结构完整性检查
  ↓
Step 3: 叙事逻辑检查
  ↓

  ↓

  ↓

  ↓
Step 7: 输出审阅报告
```

### 审阅执行

加载 `分镜评审Checklist.md`，逐项检查20项：

| 维度 | 检查内容 | 检查方法 |
|------|---------|---------|
| 叙事逻辑 | 序列连贯/景别跳跃/轴线/衔接 | 画因果链图+景别序列+俯视图 |
| 视觉设计 | 技术参数/光影色调/角色表演/转场 | 逐镜检查字段+色板对照 |
| 节奏控制 | 时长/景别变化/高潮铺垫/音画 | 时长核算+景别曲线+情绪曲线 |
| 技术规范 | 10字段/转场标注/角色锚点 | 字段完整性检查+锚点一致性 |
| AI约束 | 一致性/锚定/成功率/运动/负面 | 加载AI动画特殊检查项对照 |

### 审阅结论

- 20项全通过 → **合格**，可进入生产
- 1-3项不通过 → **有条件合格**，修改指定项后可进入生产
- 4项以上不通过 → **不合格**，需重新设计

输出标准审阅报告（模板见 `分镜评审Checklist.md` 第七章），包含：
- 评审结论
- 逐项检查结果（✓/✗ + 备注）
- 问题清单与修改建议
- 总体评价

## 五、AI动画分镜特殊约束

> 这是AI动画分镜与传统分镜的核心差异，设计/审阅时必须关注。

### 5.1 五大核心约束

| 约束 | 说明 | 检查方法 |
|------|------|---------|
| **锚定镜头策略** | 每场景第一个镜头定义角色外观和场景基调，后续镜头以此为参考 | 检查是否标注锚定镜和参考关系 |
| **跨镜角色一致性** | 同一角色在所有镜头中使用完全相同的锚点描述 | 对比所有镜头的角色描述 |
| **镜头成功率匹配** | 优先使用高成功率类型，低成功率有替代方案 | 对照AI成功率表检查 |
| **运动方向预埋** | 静态画面中预埋运动方向信息，为视频生成预留 | 检查备注栏运动预埋标注 |
| **负面提示词配置** | 通用+场景专属+角色专属负面提示词 | 检查提示词草稿完整性 |

### 5.2 锚定镜头选择标准

锚定镜头必须满足：
- 景别：LS/MS/FS（完整展示角色）
- 角度：平视/低角度（最稳定）
- 运镜：固定/慢推（最简单）
- 人物数：1人（最多2人）
- AI成功率：高

### 5.3 低成功率镜头规避策略

| 低成功率类型 | 规避策略 |
|------------|---------|
| 4+人群戏 | 拆分为单人/双人镜头，或用剪影/前后景虚化 |
| 快动作 | 用慢动作/关键帧/结果呈现法 |
| 精确连续性 | 降低连续性要求，用闪白/音效过渡 |
| 复杂运镜 | 拆分为单运镜，复杂效果后期实现 |
| 手部特写 | 用遮盖/替代物件/大特写 |

## 六、项目风格约束

> 详细规范见 `分镜风格规范.md`，以下为核心要点。

### 6.1 色板约束

| 线 | 主色 | 点缀色 | 禁止色 |
|----|------|--------|--------|
| b线 | 水泥灰+焦黑+铁锈棕 | 干涸暗褐（血）、晚秋暖琥珀（光） | 鲜红、蓝天、鲜绿 |
| d线 | 灰烬灰+水泥灰 | 铁锈红（旗）、烛火橙（灯） | 鲜艳色彩、纯白 |

**关键原则**：
- 纯黑只用于标志图案和文字
- 烛火橙永远出现在"有人在的地方"
- 血液是干涸暗褐，不是鲜红

### 6.2 角色锚点规则

- 每个镜头使用**完整锚点描述**（发型+发色+五官+体型+服装+道具）
- **禁用代词**（"她""他"）
- 跨镜头锚点**一字不差**
- 标志性道具不遗漏（红丝带/空刀鞘/黑猫等）

### 6.3 视觉母题

| 母题 | 含义 | 分镜处理 |
|------|------|---------|
| 红丝带 | 信念/"活着回来" | 特写→匹配切到红旗 |
| 空刀鞘 | 失去战斗力/被缴械 | 视线匹配特写，不解释 |
| 标志图案 | 阵营/信念 | 纯黑，只在关键镜头出现 |
| 烛火橙 | 有人在的地方/生命 | 与灰烬灰形成对比 |
| 手绘 | 记忆/人的痕迹 | 越重要越用力，线条歪扭 |
| 黑猫 | 主角的意识体 | 第1集不解释身份，留悬念 |

## 七、竖屏短剧特殊规范

> 详细规范见 `短剧铁律.md`，以下为核心要点。

### 7.1 七条铁律

1. **3秒钩子**：开头必须有冲突或悬念
2. **50-70秒一集**：6-8个镜头
3. **竖屏优先**：近景+特写为主
4. **每集一次反转**：中间有出人意料的转折
5. **结尾死钩子**：最后一秒逼观众点下一集
6. **情绪大于信息**：不灌输世界观，制造情绪
7. **AI全链路**：角色一致性是核心挑战

### 7.2 标准7镜结构

```
镜1（3秒）· 钩子 → 冲突/悬念/视觉冲击
镜2（5-7秒）· 铺垫/闪回 → 快速交代前因
镜3（8-10秒）· 反转/转机 → 局势改变
镜4（8-12秒）· 核心/对话 → 最重要的对话
镜5（5-6秒）· 行动/变化 → 角色行动
镜6（5-7秒）· 追问/揭示 → 身份揭示
镜7（5-6秒）· 死钩子 → 悬念/信息冲击
```

## 九、与下游 Skill 的衔接

本 Skill 输出结构化分镜表后，交接给 `h3-prompt-writer` 生成 H3 提示词：

```
本 Skill 输出                        h3-prompt-writer
─────────────                        ──────────────────────────
结构化分镜表（10字段/镜）    →    逐镜生成九分节 H3 提示词
空间锚点卡                   →    为 Ref2VA 提供参考图槽位分配
对白信息（说话人/内容/语言） →    格式化为 <d>[语言][性别] 内容</d>
时长与节奏                   →    对白时长核算 + 两级时间轴
AI成功率标注                 →    低成功率镜头的提示词规避策略
```

**关键交接点**：
1. 分镜表 → `h3-prompt-writer` 逐镜生成 H3 提示词
2. H3 提示词 + 分镜表 → 合并输出为分镜头需求 MD 文件
3. 分镜头需求 MD → `shot_md_to_excel.py` → 提示词审阅表 Excel
4. 用户审阅后的 Excel → `excel_to_multi_chain_json.py` → 多链生产 JSON → ComfyUI 批量生成
