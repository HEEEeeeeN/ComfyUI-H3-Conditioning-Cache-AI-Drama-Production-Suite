# 分镜导演 Skill（Storyboard Director）

> 一个面向 **AI 动画短剧生产** 的分镜设计与审阅专长（Skill）。它将专业分镜方法论沉淀为可调用的知识库与标准流程，帮助 AI 从任意剧本/场景描述出发，设计出既符合叙事规律、又满足 AI 生成可行性的结构化分镜表与 H3 视频提示词。
>
> 本 Skill 沉淀自一部 AI 动画短剧项目的真实生产实践，已在实战中验证。公开版已去除未发布作品的敏感设定信息，保留可直接复用的完整方法论。

---

## 一、触发条件

当用户需要以下操作时触发本 Skill：

| 触发场景 | 用户意图 | 输出 |
|---------|---------|------|
| **设计分镜** | "帮我设计第X集分镜" / "把这个剧本变成分镜" / "设计这场戏的分镜头" | 结构化分镜表 |
| **审阅分镜** | "帮我看看这个分镜合不合格" / "审阅一下这个分镜表" / "检查分镜质量" | 审阅报告 |
| **优化分镜** | "这个分镜有问题，帮我改" / "优化这个分镜的节奏" / "调整景别序列" | 修改后的分镜表 |
| **查询理论** | "什么是180度规则" / "推镜头和拉镜头的区别" / "恐惧情绪用什么景别" | 理论库查询结果 |

**不触发的场景**：
- "用AI生成这个分镜的画面" → 走动画生产流程
- "修改这个角色的设定" → 走角色设定流程
- "写剧本" → 走剧本创作流程

## 三、设计分镜流程

```
Step 1: 确认需求
  ↓
Step 2: 调取项目素材
  ↓
Step 3: 剧本拆解
  ↓
Step 4: 镜头序列设计
  ↓
Step 5: 逐镜技术决策
  ↓
Step 6: 节奏与时长分配
  ↓
Step 7: 生成结构化分镜表
  ↓
Step 8: 生成提示词草稿
  ↓
Step 9: 生成分镜头需求 MD 文件
  ↓
Step 10: 自检
```

### Step 1：确认需求

| 确认项 | 内容 | 影响 |
|--------|------|------|
| 剧本来源 | 哪个剧本/场景描述 | 决定拆解对象 |
| 画幅 | 9:16竖屏 / 16:9横屏 / 2.35:1宽银幕 | 决定构图和景别偏好 |
| 时长 | 竖屏55-65秒 / 横屏120-150秒 | 决定镜头数和节奏 |
| 集数/片段 | 第X集 / 预告片 / 特别篇 | 决定叙事功能 |
| 线/场景 | 项目内设定（如 b线 / d线） | 决定色板和风格 |

### Step 2：调取项目素材

加载以下素材（必加载 `分镜风格规范.md`）：
- 角色视觉锚点（从 `分镜风格规范.md` 第二章）
- 场景视觉参考（从 `分镜风格规范.md` 第三章）
- 色板规范（从 `分镜风格规范.md` 第一章）
- 短剧铁律（如为竖屏短剧，加载 `短剧铁律.md`）

### Step 3：剧本拆解

加载 `剧本拆解法.md`，执行5步拆解：

1. **通读识别戏剧要素**：主角目标/障碍/转折点/情感弧光/主题表达
2. **按场景切分**：同一时间+地点+人物的连续段落为一个场景
3. **提取视觉关键信息**：四问框架（有什么/发生什么/相机在哪/持续多久）
4. **明确展示与暗示**：什么直接呈现、什么用视觉线索暗示
5. **输出分镜设计依据**：场景信息卡 + 视觉关键信息 + 镜头序列初步规划

### Step 4：镜头序列设计

加载 `镜头序列设计法.md` + `镜头衔接逻辑.md`，执行：

1. **轴线原则**：标注对话轴线/运动轴线/视线轴线，确保无跳轴
2. **正反打设计**：对话场景设计OTS或特写交替结构
3. **景别节奏规划**：避免连续3个同级，设计渐紧/渐松模式
4. **高潮与铺垫分配**：设计情绪曲线（铺垫→升级→高潮→释放）
5. **镜头衔接逻辑**：为每对相邻镜头标注衔接类型
6. **AI成功率匹配**：标注每镜AI成功率，低成功率镜头提供替代方案

### Step 5：逐镜技术决策

加载 `景别光谱.md` + `机位角度系统.md` + `运镜类型系统.md` + `构图法则库.md` + `转场类型库.md`，为每个镜头填写：

| 决策项 | 参考文件 | 决策依据 |
|--------|---------|----------|
| 景别 | 景别光谱.md | 叙事功能 + 节奏作用 + AI成功率 |
| 机位角度 | 机位角度系统.md | 心理暗示 + 适用场景 |
| 运镜 | 运镜类型系统.md | 叙事功能 + AI生成难度 |
| 构图 | 构图法则库.md | 视觉目标 + 情绪表达 |
| 转场 | 转场类型库.md | 时空关系 + 使用频率 |
| 情绪匹配 | 情绪镜头对应表.md | 场景情绪 → 镜头参数 |

#### 5.1 官方镜头质量增强（必加载 `07_官方分镜方法论/shot_table_design.md`）

在逐镜技术决策之上，按官方方法论补齐镜头连续性、空间锚点、Hook 与逐秒指令：

| 增强项 | 依据 | 说明 |
|--------|------|-------|
| 连续性衔接 | shot_table_design.md §2.2 | 每镜如何承接上一镜结束状态、如何为下一镜铺钩 |
| 空间锚点卡 | shot_table_design.md §2.3/§4 | 固定地标 + 人物位置 + 退场人物状态 + 光位基线，四子字段必填 |
| Hook 类型 | shot_table_design.md §2.4 | 从受控词表挑一标签，用于全片 hook 分布自检 |
| 每秒指令 | shot_table_design.md §2.5 | Per-Second Directives，每条覆盖动作/镜头/空间/音频/交接五要素 |
| 音频与对白轨 | shot_table_design.md §2.6 | 旁白/对白/音效按时间锚定 + 表演备注 |

> 本项目为 2D 写实系短剧，表演不追求官方 3D 动画的夸张弹性，但"连续性/锚点/逐秒覆盖"的**结构**必须保留，以保证 Ref2VA 提示词的锚点一致。

### Step 6：节奏与时长分配

加载 `节奏控制原则.md`，执行：

1. **总时长分配**：按段落/情绪阶段分配时长
2. **单镜时长**：根据情绪强度确定每镜时长（快1-2秒/中2-4秒/慢4-6秒）
3. **节奏曲线**：设计铺垫→升级→高潮→释放的节奏变化
4. **音画同步**：标注声音内容、声音衔接方式、关键节拍切镜点

### Step 7：生成结构化分镜表

加载 `标准分镜表模板.md`，按模板输出：
- 竖屏短剧 → 使用9:16竖屏模板
- 横屏长片 → 使用16:9横屏模板

每个镜头必须包含10项标准字段：
1. 镜头号 2. 时长 3. 景别 4. 机位角度 5. 运镜 6. 构图 7. 画面内容 8. 人物动作 9. 声音 10. 转场

在 10 字段之外，按 `07_官方分镜方法论/shot_table_design.md` 为每镜补充**空间锚点卡**（固定地标/人物位置/退场人物状态/光位基线）与**连续性**（承接 S(N-1)/交接 S(N+1)），确保跨镜空间与身份一致，为 Ref2VA 提示词提供锚点基础。

### Step 8：生成 H3 视频提示词

加载 `07_官方分镜方法论/h3_prompt_workflow.md`（识别模式与输出纪律）+ `06_H3提示词指南/h3_base_prompt_guide.md`（如为全参考模式则同时加载 `h3_ref_prompt_guide.md`），为每个镜头生成 H3 格式提示词。

#### 8.1 选择提示词模式

| 模式 | 适用场景 | 参考图需求 |
|------|---------|------------|
| T2VA | 纯文本生成，无参考图 | 无 |
| I2VA | 首帧驱动 | 1张首帧图 |
| FL2VA | 首尾帧驱动 | 2张关键帧 |
| L2VA | 末帧驱动 | 1张末帧图 |
| Ref2VA | 全参考模式 | 角色+场景+道具参考图 |

本项目通常使用 **Ref2VA** 模式（角色定妆照 + 场景参考图驱动）。

#### 8.2 生成三核心字段

按 H3 官方指南严格生成：

1. **integrated_multimodal_description**：沿时间轴描述视觉风格、构图、角色外观与位置、场景与道具、动作与反应、镜头切换、对白与同步声音
2. **overall_soundscape**：1-4句英文概括环境音、物理动作声、非语言人声
3. **non_diegetic_music**：本项目统一为 `N/A`（禁止任何配乐/音乐）

#### 8.3 提示词要素中英双文标注

每个镜头的提示词要素以中英双文标注，供审阅表提取：

| 要素 | 中文 | English |
|------|------|---------|
| 镜头风格 | 电影感，实拍 | Cinematic, live-action |
| 场景 | 废弃水泥建筑内部 | Abandoned concrete building interior |
| 镜头调度 | 镜头缓慢推进，小幅度 | The camera pushes in with small amplitude at slow speed |
| 约束条件 | 角色一致性锚定 | Character consistency anchoring |

#### 8.4 摄影机运动规范

按 H3 官方指南的三维度表达摄影机运动（运动类型 + 幅度 + 速度），写为自然英文动作而非标签堆叠：

```
The camera pushes in with small amplitude at slow speed toward the folded letter.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

可用运动类型：Zoom In/Out, Push In/Pull Out, Pan Left/Right, Truck Left/Right, Tilt Up/Down, Pedestal Up/Down, Arc Shot, Tracking Shot, Static Shot, Shake, POV, Roll。

#### 8.5 对白格式与语言标注

使用稳定说话人 ID `(S1)`、`(S2)`，对白用 `<d>[语言] 内容</d>` 包裹：

```
The young woman with a quiet, breathy voice (S1) says: <d>[English] I get off at the next station.</d>
```

画外音用 `says in an off-screen voiceover`，并标注嘴唇保持闭合。

**台词语言标注规范**：

剧本中台词可能存在多种语言（原文、翻译、混用），分镜导演必须逐句检测台词语言并正确标注，确保下游 TTS 合成和提示词审阅表能准确识别。

| 语言标签 | 适用场景 | 示例 |
|---------|---------|-------|
| `[Chinese]` | 中文台词（普通话） | `<d>[Chinese] 我下一站下车。</d>` |
| `[Japanese]` | 日语台词 | `<d>[Japanese] 次の駅で降ります。</d>` |
| `[English]` | 英语台词 | `<d>[English] I get off at the next station.</d>` |
| `[Korean]` | 韩语台词 | `<d>[Korean] 다음 역에서 내립니다.</d>` |
| `[Mixed]` | 同一句中混用两种以上语言 | `<d>[Mixed] 好的, thank you very much.</d>` |
| `[Silent]` | 无台词，仅有语气词/呼吸声 | `<d>[Silent] (heavy breathing)</d>` |

**语言检测规则**：
1. **优先检测剧本原文语言**：若剧本为中文，台词默认标注 `[Chinese]`；若剧本为日文，默认 `[Japanese]`
2. **翻译剧本**：若剧本是翻译版（如日文原作译为中文），台词应标注**实际配音语言**，而非原文语言。例如中文配音的日本动画，台词标注 `[Chinese]`
3. **混用台词**：同一句中包含两种以上语言时标注 `[Mixed]`，并在 TTS 指引中注明主语言
4. **语气词**：纯语气词（"啊"、"嗯"、"ふん"）按所在语言的台词标注，不单独拆出
5. **一致性**：同一角色在不同镜头中的语言标签必须一致；若角色切换语言（如双语角色），在镜头要素中注明 "S1 switches to [English]"

**在分镜头需求 MD 中的体现**：

每镜头的"完整 H3 提示词"中，所有对白必须使用 `<d>[语言] 内容</d>` 格式。例如：

```
integrated_multimodal_description: [Shot 1] A young woman (S1) stands on a train platform. She turns and says <d>[Chinese] 我下一站下车。</d> The train arrives.
overall_soundscape: Station announcement chime, distant train horn, footsteps on concrete.
non_diegetic_music: 无背景音乐，禁止任何配乐/音乐，本镜头不要背景音乐，仅保留环境音与音效
```

**下游衔接**：
- `shot_md_to_excel.py` 生成 Excel 时，自动检测 `<d></d>` 标记，将台词部分以红色字体显示，便于审阅
- TTS 合成时，根据 `[语言]` 标签选择对应的语音模型
- 若发现台词缺少语言标签，视为格式错误，需补全后再生成分镜

### Step 9：生成分镜头需求 MD 文件

将分镜表与 H3 提示词合并输出为**分镜头需求 MD 文件**（格式规范见第十二章），包含：
- 全局信息（画幅、总时长、镜头数、风格基调）
- 逐镜头信息（基本信息 + H3 提示词要素 + 完整 H3 提示词 + 美术资产需求）
- 中英双文标注

此 MD 文件是下游 Python 工具链的输入：`shot_md_to_excel.py` 读取后生成提示词审阅表 Excel。

### Step 10：自检

加载 `分镜评审Checklist.md` + `AI动画特殊检查项.md`，执行20项自检：

- 维度1 叙事逻辑（4项）：序列连贯/景别跳跃/无跳轴/衔接逻辑
- 维度2 视觉设计（4项）：技术参数/光影色调/角色表演/转场统一
- 维度3 节奏控制（4项）：时长/景别变化/高潮铺垫/音画同步
- 维度4 技术规范（3项）：10字段齐全/转场标注/角色锚点
- 维度5 AI约束（5项）：跨镜一致性/锚定策略/成功率/运动预埋/负面提示词

完成后，加载 `07_官方分镜方法论/shot_table_design.md` §3 执行**镜头表自检门（6项强制）**：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | Hook 密度 | 每镜有 Hook 类型；每连续 3 镜至少 1 镜用 reveal/reversal/callback；首尾镜各带强 hook |
| 2 | 单镜时长 | 任何镜头 ≤15 秒，更长则拆镜 |
| 3 | 单镜角色数 | 任何镜头 ≤3 个重要角色 |
| 4 | 空间锚点继承 | 同场景跨镜固定地标与光位基线一致或含明确连续性备注 |
| 5 | 每秒指令覆盖 | 0s 到镜尾逐秒有 5 要素指令，无时间空隙 |
| 6 | 跨镜连续性 | 连续性衔接列成连续链；翻转处明确标记 |

六项全过则戳 `shot-table self-check: passed`；任一不通过，返回 Step 5 修订后重跑。

## 五、AI动画分镜特殊约束

> 这是AI动画分镜与传统分镜的核心差异，设计/审阅时必须关注。

### 5.1 五大核心约束

| 约束 | 说明 | 检查方法 |
|------|------|---------|
| **锚定镜头策略** | 每场景第一个镜头定义角色外观和场景基调，后续镜头以此为参考 | 检查是否标注锚定镜和参考关系 |
| **跨镜角色一致性** | 同一角色在所有镜头中使用完全相同的锚点描述 | 对比所有镜头的角色描述 |
| **镜头成功率匹配** | 优先使用高成功率类型，低成功率有替代方案 | 对照AI成功率表检查 |
| **运动方向预埋** | 静态画面中预埋运动方向信息，为视频生成预留 | 检查备注栏运动预埋标注 |
| **负面提示词配置** | 通用+场景专属+角色专属负面提示词 | 检查提示词草稿完整性 |

### 5.2 锚定镜头选择标准

锚定镜头必须满足：
- 景别：LS/MS/FS（完整展示角色）
- 角度：平视/低角度（最稳定）
- 运镜：固定/慢推（最简单）
- 人物数：1人（最多2人）
- AI成功率：高

### 5.3 低成功率镜头规避策略

| 低成功率类型 | 规避策略 |
|------------|---------|
| 4+人群戏 | 拆分为单人/双人镜头，或用剪影/前后景虚化 |
| 快动作 | 用慢动作/关键帧/结果呈现法 |
| 精确连续性 | 降低连续性要求，用闪白/音效过渡 |
| 复杂运镜 | 拆分为单运镜，复杂效果后期实现 |
| 手部特写 | 用遮盖/替代物件/大特写 |

## 六、项目风格约束

> 详细规范框架见 `分镜风格规范.md`，以下为核心要点。公开版中角色与场景示例已匿名化，实际使用时请替换为自有项目的锚点。

### 6.1 色板约束

设计分镜时，为每个叙事线定义主色/点缀色/禁止色，并遵守"关键颜色语义"：

- 主色用于表意与氛围，点缀色用于符号与情感焦点，禁止色避免出戏。
- 关键原则示例：纯黑只用于最严肃的符号；暖光永远出现在"有人在的地方"；血液用干涸暗褐而非鲜红。

### 6.2 角色锚点规则

- 每个镜头使用**完整锚点描述**（发型+发色+五官+体型+服装+道具）
- **禁用代词**（"她""他"）
- 跨镜头锚点**一字不差**
- 标志性道具不遗漏

### 6.3 视觉母题

| 母题 | 用途 | 分镜处理 |
|------|------|---------|
| 核心信物 | 角色的信念/约定 | 特写→匹配切到象征物 |
| 失武器 | 失去战斗力/被缴械 | 视线匹配特写，不解释 |
| 图腾符号 | 阵营/信念 | 纯黑，只在关键镜头出现 |
| 生命暖光 | 有人在的地方/生命 | 与冷灰基调形成对比 |
| 手绘痕迹 | 记忆/人的痕迹 | 越重要越用力，线条歪扭 |
| 意识体 | 悬念身份 | 前期不解释身份，留悬念 |

## 七、竖屏短剧特殊规范

> 详细规范见 `短剧铁律.md`，以下为核心要点。

### 7.1 七条铁律

1. **3秒钩子**：开头必须有冲突或悬念
2. **50-70秒一集**：6-8个镜头
3. **竖屏优先**：近景+特写为主
4. **每集一次反转**：中间有出人意料的转折
5. **结尾死钩子**：最后一秒逼观众点下一集
6. **情绪大于信息**：不灌输世界观，制造情绪
7. **AI全链路**：角色一致性是核心挑战

### 7.2 标准7镜结构

```
镜1（3秒）· 钩子 → 冲突/悬念/视觉冲击
镜2（5-7秒）· 铺垫/闪回 → 快速交代前因
镜3（8-10秒）· 反转/转机 → 局势改变
镜4（8-12秒）· 核心/对话 → 最重要的对话
镜5（5-6秒）· 行动/变化 → 角色行动
镜6（5-7秒）· 追问/揭示 → 身份揭示
镜7（5-6秒）· 死钩子 → 悬念/信息冲击
```
