## 二、轴线原则（180度规则）

### 2.1 基本规则

**定义**：想象两个对话角色之间有一条连线（"轴线"）。摄影机必须始终保持在轴线的同一侧。

**为什么**：维持空间一致性。如果角色A在左、B在右（镜1），他们在镜2中应该保持同样的左右关系。

```
        摄影机A（正确侧）         摄影机B（错误侧，跳轴）
           |                           |
     A ---------- 轴线 ---------- B
```

### 2.2 跳轴的后果

- 角色突然"换了边" → 观众方位感混乱
- 空间逻辑断裂 → 观众出戏

### 2.3 合法跳轴的方法

| 方法 | 说明 | 示例 |
|------|------|------|
| 摄影机运动展示 | 摄影机在镜头中物理越过轴线 | 摇镜头从A扫到B，过程中越过轴线 |
| 插入中性镜头 | 插入一个正对角色的镜头（在轴线上） | A-B对话中插入一个正面特写 |
| 角色移动 | 角色在场景中移动，改变轴线方向 | A走到B的另一侧，新轴线建立 |
| 动作引导 | 用一个动作转移观众注意力 | 角色倒地/爆炸/物体掉落 → 趁机跳轴 |

### 2.4 轴线的扩展应用

轴线不只是"两个角色之间的线"，还包括：

| 轴线类型 | 定义 | 应用场景 |
|---------|------|---------|
| 对话轴线 | 两个对话角色之间的连线 | 对话场景 |
| 运动轴线 | 角色运动方向的延长线 | 行走/奔跑/驾驶 |
| 视线轴线 | 角色注视方向的延长线 | 角色看向某物 |
| 兴趣轴线 | 两个被关注物体之间的连线 | 角色看向某物+被看物体 |

**应用示例**：
- 青年组长与少女组员对话 → 对话轴线，正反打保持在同一侧
- 全员集结出发 → 运动轴线，所有跟拍/侧拍保持在行进方向同一侧
- 少女组员看向远方的大楼 → 视线轴线，大楼始终在画面同一方向

## 三、30度规则

### 3.1 基本规则

**定义**：同一主体的两个相邻镜头，摄影机角度变化至少30度。

**为什么**：
- 如果两个镜头角度变化<30度 → 画面太相似 → 观众感觉是"同一个镜头切了一下" → 出戏
- 如果角度变化>30度 → 画面明显不同 → 观众理解为"新视角"

### 3.2 与景别配合

30度规则通常与景别变化配合使用：
| 景别变化 | 角度变化要求 |
|---------|------------|
| 同景别（如MS→MS） | **必须**≥30度 |
| 相邻景别（如MS→MCU） | 建议≥20度 |
| 跨级景别（如MS→ECU） | 角度变化可小（景别变化已足够区分） |

## 四、正反打设计

### 4.1 标准正反打

**定义**：对话场景中，在两个对话者之间交替切换镜头
**基础结构**：
```
镜1：OTS A→B（从A肩后看B）
镜2：OTS B→A（从B肩后看A）
镜3：OTS A→B
镜4：OTS B→A
...
```

### 4.2 正反打变体

| 变体 | 结构 | 效果 | 适用场景 |
|------|------|------|---------|
| 标准OTS | 双人过肩交替 | 建立空间关系，代入感 | 一般对话 |
| 单人特写交替 | A特写→B特写→A特写 | 更亲密，更聚焦表情 | 情感对话 |
| 角度内反打 | A正面→B正面（都面向镜头） | 打破空间感，直接面对观众 | 独白/自省/第四面墙 |
| 反应镜头优先 | A说话→切到B反应→再切回A | 强调听者反应 | 重要台词/情感转折 |

### 4.3 正反打的节奏控制

| 对话强度 | 切换速度 | 景别 |
|---------|---------|------|
| 争吵/对峙 | 快（1-2秒/切） | 近景/特写 |
| 正常对话 | 中（2-3秒/切） | 中景/中近景 |
| 沉重/情感 | 慢（3-4秒/切） | 特写（停留更久） |
| 沉默/无言 | 最慢或静止 | 反应镜头长停留 |

**应用示例**：
- 青年组长与少女初次对话 → 中速OTS，建立空间关系
- 队长审问俘虏 → 快速近景交替，传达紧张
- 角色遗言 → 慢速特写长停留，传达沉重

### 4.4 长镜头拆分（H3 生产约束）

> **H3 单镜甜点 4-6 秒、硬上限 8 秒**。剧本中的长段落必须按传统影视语言拆成短镜——正反打不只是对话的空间建立手段，更是**长镜头拆分的第一工具**。

**触发规则**：
- 镜头估算 > 8 秒 → 强制拆分
- 对白总时长 > 5 秒 → 拆成正反打交替（每句对白 ≤3-5 秒）
- 连续动作含 2 个以上节拍 → 按动作节拍拆
- 既有全景又有细节 → 拆成全景 + 特写插入

**对话拆分结构**（对白 > 5 秒必用）：
```
A 说整段台词（错误，10秒一镜）
  ↓ 拆
镜1：OTS A→B，A 说第一句（2-3秒）
镜2：B 反应特写，A 画外音继续（2秒）
镜3：OTS B→A，A 说关键句（2-3秒）
镜4：A 表情特写 + 插入镜（道具/手部/信件，1.5-2秒）
镜5：B 反应/动作收束（1.5-2秒）
```

**动作拆分结构**（连续动作 > 8 秒必用）：
```
金止戈 掩体起身→端枪→扫视→转移（错误，12秒一镜）
  ↓ 拆
镜1：全景，掩体后探头观察（铺垫，2秒）
镜2：特写，握枪指节发力（细节，2秒）
镜3：中景，起身端枪指向画右（动作起始，2.5秒）
镜4：跟随，冲出奔向下一掩体（动作主体，2.5秒）
镜5：特写，落地卧倒回头警戒（收束，2秒）
```

**拆分纪律**：
1. 每镜只承载一个核心戏剧动作或一句核心对白
2. 拆分后遵守 30 度规则与轴线规则（正反打不越轴；同侧景别相邻镜头角度 ≥30 度）
3. 拆分会增加镜头数属正常；分镜总时长与剧本段落时长一致，**镜头数增多≠时长膨胀**
4. 拆分后的短镜同样输出完整 10 字段分镜表与 H3 提示词（每镜一条）

## 五、景别节奏规划

### 5.1 避免连续同级

| 规则 | 说明 |
|------|------|
| 禁止：连续3个同级 | 如 MS→MS→MS → 节奏停滞 |
| 例外：对话正反打 | 同级OTS交替是标准做法 |
| 推荐：交替变化 | 如 ELS→MS→CU→MS→LS |

### 5.2 景别递进模式

| 模式 | 序列 | 效果 | 适用场景 |
|------|------|------|---------|
| 渐紧 | LS→MS→MCU→CU | 情绪累积到高潮 | 段落高潮 |
| 渐松 | CU→MCU→MS→LS | 情绪释放 | 段落结尾 |
| 交替 | LS→CU→MS→ECU | 动态节奏 | 动作/紧张 |
| 跳跃 | LS→CU（跳过MS） | 强烈对比 | 惊吓/发现 |
| 重复 | LS→CU→LS→CU | 节奏感/主题强调 | 平行蒙太奇 |

### 5.3 景别与叙事节拍

| 叙事节拍 | 推荐景别 | 理由 |
|---------|---------|------|
| 场景建立 | ELS/LS | 让观众先"看到"在哪 |
| 角色介绍 | MS/FS | 完整展示角色外观 |
| 对话推进 | MS/OTS | 对话的核心景别 |
| 情感升级 | MCU/CU | 聚焦表情，强化情绪 |
| 高潮爆发 | CU/ECU | 最大情绪冲击 |
| 情绪释放 | LS/ELS | 拉远，让观众"喘息" |

## 六、高潮与铺垫分配

### 6.1 情绪曲线设计

```
情绪
 ↑         ★ 高潮
 │        / \
 │       /   \     ★ 次高潮
 │      /     \   / \
 │     /       \ /   \_______ 余韵
 │    /         |
 │   /  铺垫    |
 │  /           |
 │ /            |
 |/_____________|______________→ 时间
  开场   发展   高潮   释放
```

### 6.2 景别-情绪对应分配

| 情绪阶段 | 景别策略 | 运镜策略 | 节奏 |
|---------|---------|---------|------|
| 开场（建立） | ELS→LS | 固定/慢推 | 慢 |
| 铺垫（发展） | LS→MS→MCU | 固定/中推 | 中 |
| 高潮（爆发） | CU→ECU | 快推/手持 | 快 |
| 释放（余韵） | CU→MS→LS | 慢拉/固定 | 慢 |

### 6.3 高潮前的"蓄力"

> 来源：动画大师课第四章

高潮前需要"蓄力"——通过压缩空间和加快节奏来累积张力：

```
蓄力手法：
1. 景别递收紧（MS→MCU→CU）
2. 镜头时长递缩短（3s→2s→1s）
3. 画面元素递密集（前景/背景都堆叠信息）
4. 音效/音乐递增强
→ 到达临界点后：高潮释放（CU/ECU + 慢动作/定格 + 音效爆发）
```

## 七、纵深层次与三幕结构

> 来源：动画大师课第三章/第四章

### 7.1 三阶纵深 = 三幕结构映射

| 纵深层次 | 视觉特征 | 叙事功能 | 幕对应 |
|---------|---------|---------|--------|
| 前景 | 大/实/细节丰富 | 建立具体情境，观众"落地" | 第一幕：建立 |
| 中景 | 过渡/动态线 | 引导视线运动，制造流动感 | 第二幕：发展 |
| 远景 | 小/虚/轮廓 | 悬念/揭示，高潮落点 | 第三幕：高潮/揭示 |

### 7.2 空间操控与情绪

| 空间操控 | 情绪效果 | 应用示例 |
|---------|---------|---------|
| 压缩空间（前景堆叠） | 窒息/紧张/蓄力 | 战斗前的紧张 |
| 打开纵深（拉远） | 释放/震惊/揭示 | 看到远处大楼全貌的震撼 |
| 打破透视 | 精神崩溃/超自然 | 中毒后的眩晕 |

## 八、镜头序列设计Checklist

- [ ] 轴线原则：所有对话/运动场景标注了轴线，无跳轴
- [ ] 30度规则：同景别相邻镜头角度变化≥30度
- [ ] 正反打：对话场景设计了合理的正反打结构
- [ ] 景别节奏：无连续3个同级景别（除正反打外）
- [ ] 景别递进：高潮段渐紧，释放段渐松
- [ ] 情绪曲线：设计了明确的铺垫→高潮→释放曲线
- [ ] 高潮蓄力：高潮前有景别收紧+节奏加快的蓄力段
- [ ] 纵深层次：前景/中景/远景有明确的叙事分工
