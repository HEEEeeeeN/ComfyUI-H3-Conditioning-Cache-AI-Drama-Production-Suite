# 剧本拆解法

> 分镜导演知识库 · 方法论之一
>
> 数据来源：AI-Storyboard方法论手册（Beat Breakdown Methodology）、MindStudio AI视频指南（分镜帧四问框架）

---

## 一、剧本拆解总流程

```
通读剧本 → 识别戏剧要素 → 按场景切分 → 提取视觉关键信息 → 明确展示与暗示 → 输出分镜设计依据
```

---

## 二、Step 1：通读识别戏剧要素

### 2.1 识别5大戏剧要素

| 要素 | 定义 | 提取问题 | 应用示例 |
|------|------|---------|---------|
| **主角目标** | 角色想要什么 | "这场戏的角色在追求什么？" | 青年组长：护送少女组员安全撤离废墟 |
| **障碍/冲突** | 阻止目标的东西 | "什么在阻止角色达成目标？" | 大规模坍塌、气体泄漏、体制压迫 |
| **转折点** | 局势发生改变的时刻 | "这一刻之后，事情发生了什么变化？" | 敌人被缴械 → 从战士变俘虏 |
| **情感弧光** | 角色情感如何变化 | "角色在这场戏中经历了什么情感变化？" | 从平静→警惕→信任/敌对 |
| **主题表达** | 这场戏想说什么 | "这场戏在整体主题中承担什么功能？" | 个体在灾难中的尊严与信念 |

### 2.2 通读注意事项

- 第一遍：纯读剧本，感受整体氛围和情绪流
- 第二遍：标注戏剧要素（用不同颜色标记目标/障碍/转折/情感/主题）
- 第三遍：标注视觉相关描述（环境/光线/动作/表情/道具）

---

## 三、Step 2：按场景切分

### 3.1 场景切分标准

一个"场景" = 同一时间、同一地点、同一组人物的连续段落

**切分信号**：
| 信号 | 说明 | 示例 |
|------|------|------|
| 时间变化 | "第二天""黄昏""三小时后" | → 新场景 |
| 地点变化 | "同时，在废墟深处的避难所内部" | → 新场景 |
| 人物组合变化 | 核心对话对象改变 | → 可能新场景 |
| 段落分隔 | 剧本中的空行/分隔符 | → 新场景 |

### 3.2 场景信息卡

每个场景填写一张信息卡：

```
场景编号：S01
场景名称：废墟·初次遭遇
时间：深秋下午
地点：两层混凝土建筑一楼，外墙被炮弹撕开
人物：青年组长、少女组员
情绪基调：警惕→试探→脆弱的信任
戏剧功能：主角相遇，建立关系起点
视觉关键信息：废墟内部、体积光柱、尘埃粒子、空鞘
```

## 四、Step 3：提取视觉关键信息

### 4.1 分镜帧四问框架

> 来源：MindStudio AI视频指南

对每个场景，回答四个问题：

| 问题 | 提取内容 | 示例 |
|------|---------|------|
| **场景中有什么？** | 角色/物体/背景的所有视觉元素 | 青年组长（深色外套+背后长柄武器）、少女组员（补丁制服+空鞘）、废墟建筑、碎石、弹壳、积水、体积光 |
| **发生了什么？** | 动作/运动/情绪的变化 | 队长进入废墟→少女从阴影中出现→双方对峙→少女展示空鞘→队长放下警惕 |
| **相机在哪里？** | 角度/距离/方向 | 进入门框时过肩→对峙时正反打→展示刀鞘时推到特写 |
| **持续多久？** | 每个节拍的时间 | 进入(3s)→对峙(5s)→刀鞘特写(2s)→放下警惕(3s) = 13秒 |

### 4.2 视觉关键信息提取表

| 信息类别 | 提取内容 | 分镜用途 |
|---------|---------|---------|
| **环境** | 场景的物理空间特征 | 建立镜头/环境锚点 |
| **光线** | 光源/方向/色温/强度 | 光影描述/氛围设定 |
| **天气** | 晴/阴/雨/雪/雾 | 环境描述/情绪渲染 |
| **色彩** | 主色调/点缀色 | 色板约束/色彩对比 |
| **角色状态** | 服装/表情/姿态/道具 | 角色锚点/动作设计 |
| **关键道具** | 对剧情有意义的物件 | 特写镜头/匹配转场 |
| **动作** | 角色做什么 | 运镜设计/景别选择 |
| **情绪** | 角色感受什么 | 机位角度/构图选择 |

### 4.3 光线信息提取规范

| 光线要素 | 提取内容 | 示例 |
|---------|---------|------|
| 光源 | 自然光/人工光/混合 | 阳光从破缺口射入 |
| 方向 | 顺光/逆光/侧光/顶光 | 侧光（从破缺口斜射） |
| 色温 | 暖(<3300K)/中(3300-5000K)/冷(>5000K) | 暖琥珀色（晚秋下午） |
| 强度 | 强/中/弱 | 中等（被尘埃过滤） |
| 效果 | 体积光/丁达尔效应/阴影 | 体积光（尘埃粒子形成光柱） |

## 五、Step 4：明确"展示什么、暗示什么"

### 5.1 展示与暗示的二分法

**核心原则**：不要"告诉"观众什么，而要让他们"感受"到什么。

| 类别 | 定义 | 处理方式 | 示例 |
|------|------|---------|------|
| **展示** | 直接让观众看到的视觉信息 | 用镜头明确呈现 | 空鞘 → 直接展示被缴械 |
| **暗示** | 不直接呈现，通过视觉线索让观众推断 | 用构图/光影/背景暗示 | 队长背后的红绸带 → 暗示"活着回来"的信念 |

### 5.2 暗示的视觉手段

| 暗示手段 | 说明 | 应用示例 |
|---------|------|---------|
| 背景元素 | 背景中的物件暗示角色处境/内心 | 背景挂手绘童画 → 暗示信念 |
| 光影暗示 | 光影方向/强度暗示情绪 | 半张脸在阴影中 → 暗示内心矛盾 |
| 道具暗示 | 特定道具的位置/状态暗示剧情 | 空鞘在腰间 → 暗示失去战斗力 |
| 构图暗示 | 构图方式暗示权力关系 | 角色被压在画面角落 → 暗示被压迫 |
| 反复出现 | 同一元素的重复出现暗示主题 | 红绸带反复出现 → 信念的持续 |

## 六、Step 5：输出分镜设计依据

### 6.1 分镜设计依据文档模板

```
=== 场景分镜设计依据 ===

场景编号：S01
场景名称：废墟·初次遭遇
总时长：约13秒
画幅：9:16竖屏

【视觉关键信息】
- 环境：两层混凝土废墟，外墙破缺口，碎石/弹壳/积水
- 光线：侧光，暖琥珀色，体积光
- 色调：灰水泥+深影+晚秋暖琥珀光
- 角色：青年组长（深色外套+长柄武器+红绸带）、少女组员（补丁制服+空鞘+左眉伤口）

【戏剧要素】
- 目标：青年组长寻找安全路线 / 少女组员寻求庇护
- 障碍：互不信任 / 语言障碍 / 灾难环境
- 转折：少女组员展示空鞘 → 从对峙到信任
- 情感弧光：警惕→试探→脆弱的信任
- 主题功能：灾难中的人性微光

【展示】
- 废墟环境 → 建立镜头
- 双方对峙 → 正反打
- 空鞘 → 特写
- 青年组长放下警惕 → 表情变化

【暗示】
- 红绸带在背景飘动 → 信念
- 少女组员左眉伤口 → 创伤（不解释，让观众看到）
- 积水中的倒影 → 两个世界的镜像

【镜头序列初步规划】
1. 建立镜头：废墟内部全景（ELS, 3s）
2. 青年组长进入：过肩门框构图（OTS, 2s）
3. 少女组员出现：阴影中的剪影（MS, 2s）
4. 对峙正反打：双人OTS交替（OTS, 2x2s）
5. 刀鞘特写：推到ECU（CU→ECU, 2s）
6. 青年组长表情变化：近景（CU, 2s）
```

## 七、9拍节拍板（Beat Breakdown）

> 来源：AI-Storyboard方法论手册

对于较长的内容（如预告片、长篇集），使用9拍节拍板来提取核心叙事结构：

### 7.1 节拍选择标准

一个好的节拍是：
1. **转折点**：发生了改变（角色学到新信息/做出决定/遇到障碍）
2. **视觉独特**：可以用一张有冲击力的画面代表
3. **故事必需**：删除它会形成叙事空缺
4. **情感显著**：情绪高度或张力点

### 7.2 9拍分布策略

| 位置 | 叙事功能 | 预告片应用示例 |
|------|---------|--------------|
| 拍1 | 开场建立 | 城市废墟远景 |
| 拍2 | 角色介绍 | 青年组长正面 |
| 拍3 | 触发事件 | 灾难/入侵信号 |
| 拍4 | 障碍/升级 | 塌方/伤亡 |
| 拍5 | 中点转折 | 关键决定时刻 |
| 拍6 | 升级/加剧 | 全员集结出发 |
| 拍7 | 高潮 | 战斗/牺牲 |
| 拍8 | 解决 | 纪念/告别仪式 |
| 拍9 | 结尾/余韵 | 废墟清晨/旗帜飘扬 |

### 7.3 节拍描述格式

```
**节拍1**
- 场景：开场，城市废墟外观
- 描述：灰烬灰天空下，废墟的不规则垂直结构占据画面
- 叙事目的：建立世界观和空间感，让观众"进入"故事的世界
```
