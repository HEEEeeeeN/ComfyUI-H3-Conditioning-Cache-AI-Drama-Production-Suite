| **高** | 无角色建立镜头 | 纯环境/建筑/风景 | 背景稳定，无角色崩坏风险 | 优先用于场景建立 |

## 二、规避策略与替代方案

### 2.1 群戏规避策略

| 策略 | 说明 | 示例 |
|------|------|------|
| **拆分法** | 将群戏拆分为多个单人/双人镜头 | 4人对话→2组双人OTS |
| **前后景法** | 前景1-2人清晰，其他人虚化在背景 | 前景双人对话，背景人群虚化 |
| **剪影法** | 多人用剪影/背影处理，不需细节 | 远景中多人剪影行进 |
| **顺序出场法** | 群戏角色逐个出场，每镜只聚焦1-2人 | 镜1角色A，镜2角色B，镜3双人 |
| **建立+切角法** | 用一个群戏建立镜头交代所有人，然后切到单人/双人 | 镜1群戏LS(建立)，镜2-5单人CU(叙事) |

### 2.2 快动作规避策略

| 策略 | 说明 | 示例 |
|------|------|------|
| **慢动作法** | 将快动作放慢，用慢动作呈现 | 拔刀瞬间→慢动作+定格 |
| **关键帧法** | 只呈现动作的起始帧和结束帧，中间用音效/闪白过渡 | 出拳→[闪白]→命中 |
| **结果呈现法** | 不拍动作过程，只拍动作结果 | 不拍打斗过程→切到倒地的敌人 |
| **视线引导法** | 用角色视线引导，不直接拍动作 | 角色看向画外→音效→角色表情反应 |

### 2.3 复杂运镜规避策略

| 策略 | 说明 | 示例 |
|------|------|------|
| **拆分运镜** | 将复合运镜拆分为多个单运镜镜头 | 手持+跟拍→镜1跟拍(固定方向)+镜2手持(微晃) |
| **简化运镜** | 将复杂运镜简化为固定+单方向推拉 | 升降+旋转→镜1升降(固定)+镜2固定旋转感 |
| **后期模拟** | 运镜效果在后期实现，AI生成用固定机位 | 手持感→AI固定生成+后期添加手持抖动 |

## 三、锚定镜头策略

### 3.1 什么是锚定镜头

**定义**：场景中第一个定义角色外观和场景基调的镜头。后续所有镜头以此为参考图，确保跨镜头一致性。

**锚定镜头的职责**：
1. 完整展示角色外观（发型/发色/五官/服饰/道具）
2. 建立场景视觉基调（色调/光影/氛围）
3. 为后续镜头提供AI生成的参考图

### 3.2 锚定镜头选择标准

| 标准 | 要求 | 原因 |
|------|------|------|
| 景别 | LS/MS/FS | 需完整展示角色外观 |
| 角度 | 平视/低角度 | 最稳定，变形最少 |
| 运镜 | 固定/慢推 | 运镜越简单，AI生成越稳定 |
| 人物数 | 1人（最多2人） | 单人一致性最好 |
| 光影 | 均匀/正面光 | 避免复杂阴影导致角色特征丢失 |
| 成功率 | 高 | 锚定镜头必须成功，否则全场景废 |

### 3.3 锚定链构建

```
锚定镜1（场景建立+角色定妆）
    ↓ 提取参考帧
后续镜2（参考锚定镜1）
    ↓ 提取参考帧
后续镜3（参考锚定镜1或镜2）
    ↓ 提取参考帧
...
```

**锚定链规则**：
- 每个新场景的第一个镜头是该场景的锚定镜
- 后续镜头在提示词中标注"参考[锚定镜号]"
- 如中途角色外观变化（换装/受伤），需新的锚定镜
- 锚定链不宜过长（建议≤8镜），过长需重新建立锚定

### 3.4 分镜表中的锚定标注

```
镜1 [锚定镜]：LS, eye-level, 固定. 主角青年（完整锚点）站在废墟入口.
    → 提示词草稿：[完整提示词] → 输出帧作为镜2-镜6的参考图

镜2 [参考镜1]：MCU, eye-level, 慢推. 主角青年（同锚点）面部表情.
    → 提示词草稿：[提示词] + 参考图：镜1输出帧

镜3 [参考镜1]：CU, eye-level, 固定. 主角青年（同锚点）眼部特写.
    → 提示词草稿：[提示词] + 参考图：镜1输出帧
```

## 四、跨镜头角色一致性保障

### 4.1 一致性检查清单

| 检查项 | 要求 | 检查方法 |
|--------|------|---------|
| 发型发色 | 所有镜头中完全相同 | 对比所有镜头的角色锚点描述 |
| 五官特征 | 面容/眼色/脸型不变 | 对比锚定镜与后续镜头 |
| 服饰 | 服装/配饰/道具不变（除非剧情需要） | 逐镜检查服装描述 |
| 体型 | 身高/体形比例不变 | 全身镜头中对比 |
| 标志性道具 | 不遗漏（如角色专属配饰/武器） | 逐镜检查道具是否出现 |
| 光影一致 | 同场景光源方向不突变 | 检查光影标注 |

### 4.2 一致性保障的提示词规范

**角色锚点模板**（每个镜头必须完整重复）：

```
[角色名]（[年龄]岁，[身高]cm，[发色发型]，[面容特征]，[服装描述]，[标志性道具]）
```

**示例（主角青年）**：
```
主角青年（26岁，168cm，黑色短发瘦削，高颧骨眼神专注神情冷峻，褪色旧制服多处缝补，腰间悬着专属武器）
```

**规则**：
- 每个镜头的提示词中完整重复角色锚点，不用代词
- 锚点描述在所有镜头中**一字不差**
- 如有外观变化（换装/受伤/时间流逝），标注"变更：[具体变化]"

### 4.3 环境一致性保障

| 检查项 | 要求 |
|--------|------|
| 场景布局 | 建筑/家具/道具位置跨镜一致 |
| 光源 | 同场景光源方向/色温不变 |
| 天气 | 同场景天气一致（除非剧情变化） |
| 色调 | 同场景色调符合项目色板规范 |
| 时间 | 同场景时间一致（日/夜/黄昏） |

## 五、运动方向预埋

### 5.1 什么是运动方向预埋

**定义**：在静态分镜画面中，通过角色姿态、构图、视线等元素，为后期视频生成预留运动方向信息。

**为什么需要**：AI图生视频模型需要明确的运动方向指引，否则可能生成随机/矛盾的运动。

### 5.2 运动方向预埋的要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **角色姿态** | 角色身体朝向暗示运动方向 | 身体前倾+左脚在前→向左走 |
| **视线方向** | 角色视线暗示即将运动/关注的方向 | 看向右方→下一步向右运动 |
| **动势线** | 构图中的引导线暗示运动轨迹 | 斜线构图→沿斜线方向运动 |
| **模糊方向** | 背景模糊方向暗示运镜方向 | 水平模糊→横移运镜 |
| **备注标注** | 在分镜表中明确文字标注 | "运动预埋：向右慢走" |

### 5.3 运动方向预埋标注格式

在分镜表备注栏标注：
```
运动预埋：[运动类型]+[速度]+[方向]
示例：
- 运动预埋：向右慢走
- 运动预埋：向前快跑
- 运动预埋：原地转身左转
- 运动预埋：向上抬头慢
- 运动预埋：镜头向右慢移（无角色运动）
```

## 六、负面提示词配置

### 6.1 通用负面提示词

```
通用负面提示词（所有镜头必带）：
worst quality, low quality, bad anatomy, bad hands, missing fingers, 
extra fingers, extra limbs, deformed, disfigured, mutation, 
merged faces, merged bodies, cloned face, swapped face, 
inconsistent clothing, clothing change, 
background change, flickering background, random objects, 
watermark, signature, text, logo,
blurry, out of focus, overexposed, underexposed
```

### 6.2 场景专属负面提示词

| 场景类型 | 额外负面提示词 | 原因 |
|---------|--------------|------|
| 群戏（3人+） | extra people, merged bodies, face swap, too many fingers | AI群戏易崩 |
| 手部特写 | extra fingers, missing fingers, deformed hands, merged hands | 手部是AI重灾区 |
| 快动作 | motion blur, deformed limbs, extra limbs | 快动作易变形 |
| 双人对话 | face swap, identity change, clothing change | 双人易"换脸" |
| 建筑场景 | distorted architecture, impossible geometry, floating objects | AI建筑易畸变 |
| 食物/餐具 | deformed food, impossible utensils, merged objects | AI小物件易崩 |

### 6.3 角色类型专属负面提示词

| 角色类型 | 额外负面提示词 | 原因 |
|------|--------------|------|
| 主角青年（神情冷峻设定） | smile, happy expression, clean uniform | 角色设定神情冷峻、衣着有破损 |
| 少女组员（带伤设定） | healthy skin, clean face, intact hands | 角色带伤、有特殊体质设定 |
| 高大壮汉角色 | normal proportions, slim build | 角色体型异常壮大 |
| 机械/义体角色 | human skin, no seams, natural neck | 角色为机械体、有接缝线 |

## 七、AI动画分镜设计原则总结

### 7.1 五大核心原则

| 原则 | 说明 | 优先级 |
|------|------|:------:|
| 1. 锚定优先 | 每场景先设计锚定镜头，确保角色和场景基调 | 最高 |
| 2. 成功率导向 | 优先使用高成功率镜头类型，低成功率有替代方案 | 高 |
| 3. 一致性保障 | 完整锚点+固定Seed+参考图链 | 高 |
| 4. 运动预埋 | 静态画面中预埋运动方向信息 | 中 |
| 5. 负面配置 | 通用+场景专属+角色类型专属负面提示词 | 中 |

### 7.2 AI分镜 vs 传统分镜的差异

| 维度 | 传统动画分镜 | AI动画分镜 |
|------|------------|-----------|
| 镜头数量 | 可以多（手绘可控） | 需控制（每镜都需AI生成+检查） |
| 群戏 | 可行（画师可控制每角色） | 谨慎（4人+易崩） |
| 快动作 | 可行（画师可逐帧控制） | 谨慎（AI动作易变形） |
| 运镜 | 可行（画师可模拟任何运镜） | 简化（复杂运镜AI不稳定） |
| 一致性 | 画师手动保证 | 需锚定策略+参考图链 |
| 连续性 | 逐帧可控 | 帧间连续性不可控 |
| 运动方向 | 无需预埋 | 需预埋（为视频生成预留） |
