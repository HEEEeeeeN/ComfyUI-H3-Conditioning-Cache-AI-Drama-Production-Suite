# 参考案例：竖屏短剧分镜 · 文学版 → 结构化版

> 分镜导演知识库 · 参考案例之一
>
> 用途：展示如何将文学描述版分镜改造为结构化分镜表版，作为分镜导演的工作范例
>
> 源文件：（文学版分镜，已脱敏）
> 改造目标：符合《标准分镜表模板》《分镜风格规范》《短剧铁律》《AI动画特殊检查项》的结构化分镜表
>
> 改造原则：
> 1. **文学版**以段落叙事为主，重在情绪渲染和画面想象；**结构化版**以字段表格为主，重在可执行性和AI生成约束
> 2. 文学版中的模糊描述（"极近距""三帧叠影"）转换为标准术语（ECU、叠影残影构图）
> 3. 文学版中隐含的机位/运镜/构图信息提取为显式字段
> 4. 补充文学版未涉及的AI约束信息（成功率标注、规避策略、运动方向预埋、锚定镜头策略）
> 5. 角色描述全部替换为完整锚点，禁用代词
> 6. 色调统一标注为主线色板（水泥灰+铁锈棕+干涸暗褐+晚秋暖琥珀光）

## 十一、与文学版的对比说明（改造了什么，为什么）

### 11.1 改造总览

| 维度 | 文学版 | 结构化版 | 改造原因 |
|------|--------|---------|---------|
| **格式** | 段落叙事，文学描述 | 10项标准字段表格 | 结构化版可直接用于AI生成和团队执行，字段无歧义 |
| **景别** | "极近距""三连跳剪" | ECU、MS→CU→MS | 标准术语消除歧义，AI生成可直接使用 |
| **机位角度** | 隐含在描述中（"仰视""POV"） | 显式标注（平视/POV/低角度虫视） | 每镜必须显式标注，避免遗漏 |
| **运镜** | 隐含（"跟拍手持感""环绕"） | 标准术语（手持/跟/环绕/拉） | 显式标注便于AI运镜参数配置 |
| **构图** | "脸占70%""三帧叠影" | 负空间/三帧叠影残影/对比/框架/引导线 | 标准术语+原描述细节保留 |
| **角色描述** | 混用代词（"她""他"）和角色名 | 全部完整锚点，禁用代词 | AI跨镜一致性核心要求 |
| **色调** | 散落在画面描述中 | 统一标注主线色板（水泥灰+铁锈棕+干涸暗褐+晚秋暖琥珀光） | 符合分镜风格规范色板约束 |
| **转场** | 未标注转场类型 | 每镜标注转场类型+衔接类型 | 符合分镜评审Checklist第⑭项 |
| **AI约束** | 无 | 成功率标注+规避策略+运动预埋+负面提示词 | 文学版不涉及AI生成约束，结构化版必须补充 |
| **锚定策略** | 无 | 镜1/3/4三重锚定+参考关系标注 | 文学版不涉及锚定策略，结构化版必须补充 |

### 11.2 具体改造细节

**1. 景别术语化**
- 文学版"极近距"→ 结构化版 ECU（大特写）
- 文学版"三连跳剪"→ 结构化版 MS→CU→MS（三连跳剪，每帧约1.5-2秒）
- 文学版"POV"→ 结构化版 POV（第一人称）→ 后半段逆光LS剪影
- 文学版"画面往后拉"→ 结构化版 LS→ELS（拉远）

**2. 机位角度显式化**
- 文学版镜3"少女视角"→ 结构化版 POV（少女队员视角，低角度虫视感——爬行视角仰视）
- 文学版镜4"仰视"→ 结构化版 POV（少女队员视角仰视）→ 平视（第三人称侧视）

**3. 运镜标准化**
- 文学版"跟拍手持感"→ 结构化版 手持（侧面跟拍手持感）
- 文学版"镜头开始环绕"→ 结构化版 跟（少女快走两步追上）→ 环绕（从身后绕到面前，弧线运镜）
- 文学版"画面往后拉"→ 结构化版 拉（慢拉，画面往后拉）

**4. 构图术语化**
- 文学版"脸占屏幕70%，额头抵顶部，下巴在1/3处"→ 结构化版 负空间（脸占画面70%，额头抵画面顶部，下巴在画面1/3处，上方留白）
- 文学版"三帧叠影残影感"→ 结构化版 三帧叠影残影感（跳剪帧之间叠化残影）
- 文学版"少女在画面右下仰视，队长在画面左上"→ 结构化版 对比构图（少女队员右下小弱，青年队长左上大强）+ 引导线（影子横贯）
- 文学版"竖屏变成画面中方形窗口"→ 结构化版 框架构图（方形窗口）+ 对比（一整排人影）+ 负空间（窗口外灰白薄烟）

**5. 角色锚点完整化**
- 文学版用"她""他""猫"等代词 → 结构化版每个镜头完整重复角色锚点
- 示例：文学版"队长蹲在地上手伸向少女"→ 结构化版"青年队长（26岁，168cm，黑色短发瘦削，高颧骨眼神如井完全无表情，褪色橄榄绿反抗军制服无军衔多处缝补但干净，背后粗布裹长刀80cm褪色红丝带，腰间无佩枪）蹲在地上，右手伸向少女队员"

**6. 色板统一化**
- 文学版散落的"火光白烟""水泥灰""焦黑"→ 结构化版统一标注主线色板
- 场景1（废墟内部）: 深灰+水泥灰+晚秋暖琥珀光（god rays）+干涸暗褐（血迹）
- 场景2（户外战场）: 水泥灰+铁锈棕+焦黑建筑+灰白薄烟+干涸暗褐（血迹）
- 血液统一为"干涸暗褐"（非鲜红），符合主线色板

**7. AI约束补充（文学版完全没有）**
- 成功率标注：7个镜头逐一标注高/中/低成功率
- 规避策略：镜5（前后景法）、镜6（拆分运镜）、镜2（关键帧法/碎片化跳剪）
- 运动方向预埋：7个镜头逐一标注运动预埋
- 锚定策略：镜1/3/4三重锚定+参考关系链
- 负面提示词：通用+场景专属+角色专属

**8. 转场标注补充**
- 文学版未标注转场类型 → 结构化版每镜标注转场+衔接类型
- 衔接类型：情绪延续（镜1→2）、情绪升级（镜2→3）、因果链条（镜3）、视线匹配（镜4）、进出画方向（镜5）、动作连贯（镜6）、情绪对比（镜7）
