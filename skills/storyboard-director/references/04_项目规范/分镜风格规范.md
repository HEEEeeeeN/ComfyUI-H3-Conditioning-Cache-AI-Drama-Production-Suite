## 一、整体色板规范

### 1.1 故事线A（示例：新秩序阵营）色板

| 色系 | 颜色 | 使用场景 | 占比 |
|------|------|---------|:----:|
| 主色 | 灰烬灰（带淡蓝调） | 天空、远山、远景废墟 | 60% |
| 主色 | 水泥灰（偏冷中灰） | 大型建筑外墙、废墟建筑、街道 | 20% |
| 点缀 | 铁锈红（带棕调暗红） | 锈迹、血迹、褪色旗帜、手绘图案 | 8% |
| 点缀 | 阵营图腾黑（纯黑） | 只用于阵营特定图案和字体 | 5% |
| 生命 | 烛火橙（带黄调暖橙） | 建筑内部灯光、焊接火花、长明火 | 5% |
| 生命 | 土黄（带灰调米黄） | 防护面罩反光、恶劣环境下皮肤、手工制品 | 2% |

**关键原则**：
- 纯黑只用于阵营特定图案和文字——视觉"锚"
- 烛火橙永远出现在"有人在的地方"
- 天空永远是灰烬灰带淡蓝调，不是死灰

### 1.2 故事线B（示例：战时背景）色板

| 元素 | 颜色倾向 | 说明 |
|------|---------|------|
| 军装 | 褪色橄榄绿、发白的补丁 | 示例角色A/示例角色B服装基调 |
| 天空 | 水泥灰、受潮木炭色 | 该线天空永远不是蓝天 |
| 建筑 | 焦黑、水泥灰、铁锈棕 | 战后废墟基调 |
| 血液 | 干涸暗褐（非鲜红） | 避免过度暴力感 |
| 烟雾 | 灰白薄烟（非浓黑） | 火药烟雾而非油烟 |

### 1.3 分镜色板应用规则

| 场景类型 | 主色 | 点缀色 | 禁止色 |
|---------|------|--------|--------|
| 故事线B户外 | 水泥灰+铁锈棕 | 干涸暗褐（血迹） | 鲜红、蓝天、鲜绿 |
| 故事线B废墟内部 | 深灰+水泥灰 | 晚秋暖琥珀光（god rays） | 鲜亮色彩 |
| 故事线A建筑外部 | 灰烬灰+水泥灰 | 铁锈红（旗帜） | 鲜艳色彩 |
| 故事线A建筑内部 | 水泥灰+烛火橙 | 土黄（手工制品） | 纯白、鲜蓝 |
| 故事线A仪式场景 | 黑色礼服+灰天 | 长明火橙+铁锈红（旗） | 鲜艳色彩 |

## 二、核心角色视觉锚点

### 2.1 角色锚点完整描述（分镜用）

**使用规则**：每个镜头中角色出现时，必须完整重复以下锚点描述，不得使用代词。

#### 示例角色A（主角）

```
示例角色A（[年龄]，[身高]，黑色短发瘦削，高颧骨，眼神深邃完全无表情，褪色橄榄绿制式服装无军衔多处缝补但干净，背后粗布裹长刀带褪色褪色丝带，腰间无佩枪，手上是长期劳作留下的茧）
```

| 维度 | 特征 |
|------|------|
| 面容 | 瘦削短发，高颧骨，眼神深邃，完全无表情 |
| 发色发型 | 黑色短发，简洁不打理 |
| 服装 | 褪色橄榄绿制式服装，无军衔，多处缝补但干净 |
| 标志道具 | 背后粗布裹长刀（约80cm，褪色褪色丝带） |
| 手部 | 长期劳作留下的茧，不细腻 |
| 站姿 | 重心微偏一侧，两臂不交叉 |

#### 示例角色B

```
示例角色B（[年龄]，[身高]，营养不良偏瘦但结实，深棕色不整齐的短发粘着灰尘血渍，瞳孔颜色特殊眼神警觉，眉骨处有伤口，打补丁制式服装比示例角色A更旧更不合身多处撕裂带干涸血迹）
```

| 维度 | 特征 |
|------|------|
| 面容 | 特殊颜色瞳孔，眼神警觉，眉骨处伤口 |
| 发色发型 | 深棕色，参差不齐，粘着灰尘血渍 |
| 身体 | 先天性的轻度体态特征（背景设定所致） |
| 服装 | 打补丁制式服装，比示例角色A更旧更不合身 |
| 道具 | 腰间空鞘（被缴械） |

#### 示例角色C（故事线A）

```
示例角色C（[年龄]，[身高]，特殊发型挑染渐变高马尾，全黑紧身战术服装+轻量化防护背心+黑色战术裤+作战靴，肩带阵营徽章，随身旧式怀表，陶土口哨裂了又粘）
```

**特殊形态（某集）**：
```
示例角色C·灵体形态形态（纯黑色小动物，特殊色瞳，头顶一撮极细微的异色毛，趴在示例角色A肩头，眼神不像动物像在评估）
```

#### 示例角色D

```
示例角色D（[身高]，[体重]，背景设定导致体态异常壮大，下颚比常人大一圈，板寸自己剃的歪歪扭扭，最大号军装仍显小袖口裤腿短一截，改装重武器单手操作）
```

#### 示例角色E

```
示例角色E（约[身高]cm，瘦削营养不良，眉尾一道旧伤疤笑时微微扭曲，白色传统服饰样式破烂但洗干净补了又补，胸口贴身份木牌）
```

### 2.2 角色锚点使用Checklist

- [ ] 每个镜头使用完整锚点描述（非代词）
- [ ] 锚点描述在所有镜头中一字不差
- [ ] 标志性道具不遗漏（褪色丝带/空鞘/小动物等）
- [ ] 如有外观变化，标注"变更：[具体变化]"
- [ ] 锚点与设定文档一致

## 四、核心视觉符号

### 4.1 视觉母题（反复出现的符号）

| 符号 | 含义 | 出现形式 | 分镜处理 |
|------|------|---------|---------|
| **褪色丝带** | 信念/归来的承诺 | 示例角色A背后大刀上的褪色褪色丝带 | 特写→匹配切到旗帜（图形匹配） |
| **空鞘** | 失去战斗力/被缴械 | 示例角色B腰间空鞘 | 视线匹配特写，不解释让画面说话 |
| **阵营图腾** | 新秩序阵营/信念 | 旗帜上的图案、面具手绘 | 纯黑，只在关键镜头出现 |
| **烛火橙** | 有人在的地方/生命 | 建筑内部灯光、长明火、焊接火花 | 与灰烬灰形成对比 |
| **手绘** | 记忆/人的痕迹 | 建筑满墙手绘、后背红油漆字 | 越重要越用力，线条歪歪扭扭 |
| **小动物** | 示例角色C的灵体形态 | 趴在示例角色A肩头，特殊色瞳 | 某集不解释身份，留作悬念 |

### 4.2 视觉母题的分镜运用

```
母题运用原则：
1. 母题应反复出现（每集至少1-2次），但不解释——让观众自己发现
2. 母题出现时用特写/视线匹配强调，但不配解说
3. 母题可做匹配转场的连接元素（如褪色丝带→旗帜）
4. 母题的颜色必须在色板范围内（褪色丝带=铁锈红，不是鲜红）
```

## 五、分镜风格约束总表

### 5.1 必须遵守的约束

| # | 约束 | 说明 |
|---|------|------|
| 1 | 色板约束 | 所有镜头色调必须符合各线色板，禁止使用色板外颜色 |
| 2 | 角色锚点 | 所有镜头使用完整角色锚点描述，不用代词 |
| 3 | 道具不遗漏 | 标志性道具必须出现在每个有角色的镜头中 |
| 4 | 天空色 | 故事线B天空=水泥灰/木炭色；故事线A天空=灰烬灰带淡蓝调 |
| 5 | 血液色 | 干涸暗褐，非鲜红 |
| 6 | 纯黑限制 | 纯黑只用于阵营特定图案和文字 |
| 7 | 烛火橙 | 永远出现在"有人在的地方" |
| 8 | 视觉母题 | 褪色丝带/空鞘/图腾/手绘等母题反复出现但不解释 |

### 5.2 分镜风格自检

```
--- 分镜风格自检 ---
[✓/✗] 所有镜头色调符合各线色板
[✓/✗] 所有角色使用完整锚点描述
[✓/✗] 标志性道具（褪色丝带/空鞘/小动物等）不遗漏
[✓/✗] 天空颜色符合线别（故事线B水泥灰/故事线A灰烬灰）
[✓/✗] 血液颜色为干涸暗褐（非鲜红）
[✓/✗] 纯黑仅用于阵营特定图案和文字
[✓/✗] 烛火橙出现在有人场景
[✓/✗] 视觉母题至少出现1次
```
