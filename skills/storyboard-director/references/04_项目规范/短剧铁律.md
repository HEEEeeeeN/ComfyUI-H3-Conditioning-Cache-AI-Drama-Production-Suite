## 一、短剧7条铁律总表

| # | 铁律 | 核心要求 | 数据依据 |
|---|------|---------|---------|
| 1 | 3秒钩子 | 开头必须有冲突或悬念 | 完播率不到20%的用户都是前3秒划走的 |
| 2 | 50-70秒一集 | 6-8个镜头，台词只留核心 | 用户注意力窗口 |
| 3 | 竖屏优先 | 近景+特写为主 | 平台流量全面向竖屏倾斜 |

| 7 | AI全链路 | 剧本→角色→分镜→视频→剪辑 | 角色一致性是核心挑战 |

## 二、各铁律详细说明

### 2.1 3秒钩子

**定义**：开头第1个镜头（前3秒）必须有冲突、悬念或强烈视觉冲击。

**为什么**：完播率不到20%的用户都是前3秒划走的。前3秒决定了80%的观众去留。

**分镜要求**：
- 镜1必须是全片最具冲击力的画面之一
- 3秒内必须让观众看到"冲突"或"悬念"
- 不铺垫、不建立、不交代背景——直接进入冲突

**合格钩子类型**：

| 类型 | 说明 | 通用示例 |
|------|------|---------|
| 危险钩子 | 角色处于危险中 | 镜1：示例角色A满脸血，瞳孔涣散，濒死状态 |
| 反转钩子 | 与预期相反的画面 | 角色微笑着做可怕的事 |
| 悬念钩子 | 让观众问"为什么" | 角色看向画外，震惊表情 |
| 视觉钩子 | 极强的视觉冲击 | 爆炸/血/极端构图 |

**不合格的开头**：
- 风景空镜（没有冲突）
- 角色走路（没有悬念）
- 旁白交代背景（信息而非情绪）
- 字幕（观众不会读）

---

### 2.2 50-70秒一集

**定义**：每集总时长50-70秒，镜头数6-8个。

**为什么**：用户注意力窗口有限，短剧的"短"是核心竞争力。

**分镜要求**：

| 参数 | 要求 | 说明 |
|------|------|------|
| 总时长 | 55-65秒（含转场） | 50秒以下信息不够，70秒以上节奏拖 |
| 镜头数 | 6-8个 | 少于6个节奏太慢，多于8个每镜太短 |
| 平均每镜 | 5-8秒 | 竖屏允许比横屏更长的单镜 |
| 台词 | 极简，只留核心 | 砍掉所有铺垫和解释 |
| 台词量 | 每集3-5句 | 每句不超过10个字 |

**台词精简原则**：
```
原则：能不说话就不说话，能用画面说的就不用台词

保留：推动剧情的核心台词 / 揭示角色的关键台词 / 死钩子台词
砍掉：铺垫台词 / 解释台词 / 闲聊 / 旁白
```

**通用示例**（核心台词精简）：
```
保留3句：
1. 示例角色B："你是谁。"（追问——核心转折）
2. 示例角色A："我是[组织/身份]的[职位]，[姓名]。"（身份揭示）
3. 示例角色A：一句富含身份与使命的短句。（身份+使命）

砍掉：所有背景交代、所有情感铺垫、所有解释性台词
```

### 2.3 竖屏优先

**定义**：画幅9:16竖屏，景别以近景/特写为主。

**为什么**：平台流量全面向竖屏倾斜。竖屏是短剧的默认格式。

**分镜要求**：

| 参数 | 要求 | 说明 |
|------|------|------|
| 画幅 | 9:16竖屏 | 如1080×1920 |
| 景别偏好 | CU/MCU/ECU为主 | 竖屏画幅适合近景 |
| 景别占比 | 近景+特写≥60% | 远景在竖屏中信息量不足 |
| 构图调整 | 垂直方向优先 | 竖屏垂直空间比水平空间重要 |

**竖屏vs横屏构图差异**：

| 构图要素 | 横屏做法 | 竖屏调整 |
|---------|---------|---------|
| 留白方向 | 水平留白（左右） | 垂直留白（上下） |
| 孤独感 | 水平负空间 | 上方留白（天空/空旷） |
| 压迫感 | 底部压迫 | 两侧挤压（竖屏两侧窄） |
| 希望感 | 水平开放（地平线） | 垂直延伸（天空/高建筑） |
| 双人对话 | 左右分屏 | 上下分屏或单人交替 |

---

### 2.4 每集一次反转

**定义**：每集中间必须有至少一次出人意料的转折。

**为什么**：维持观众留存，防止"猜到结尾"导致划走。

**分镜要求**：
- 反转通常在第3-4个镜头（全片中段）
- 反转必须改变观众对前面镜头的理解
- 反转不需要解释——让观众带着疑问看到结尾

**反转类型**：

| 类型 | 说明 | 通用示例 |
|------|------|---------|
| 身份反转 | 角色身份与预期不同 | 被救的人其实是敌方角色 |
| 局势反转 | 局势突然改变 | 被追杀的人突然变成追杀者 |
| 情感反转 | 情感突然改变 | 以为要被杀→结果被救 |
| 信息反转 | 新信息改变理解 | 发现角色不是在看敌人而是在看队友 |

**通用单集反转结构示例**：
```
镜1-3：观众以为示例角色A濒死了（绝望）
→ 镜3反转：遮挡被移开，三个剪影出现（希望/转机）
→ 镜4-6：观众以为只是普通救援
→ 镜6反转：示例角色A的身份揭示（出人意料）
→ 镜7死钩子："还有八年"——刚刚65秒只是第一天
```

---

### 2.5 结尾死钩子

**定义**：最后一秒必须有悬念/反转/未尽之言，逼观众点下一集。

**为什么**：转化率核心——让观众"不得不"看下一集。

**分镜要求**：
- 最后一镜（镜7或镜8）必须是死钩子
- 死钩子用信息/悬念/情绪制造"未完成感"
- 死钩子不需要解答——解答在下一集

**死钩子类型**：

| 类型 | 说明 | 通用示例 |
|------|------|---------|
| 信息钩子 | 抛出关键信息 | "还有八年"（字幕） |
| 悬念钩子 | 制造疑问 | 那只小动物是谁？ |
| 反转钩子 | 最后一秒反转 | 角色突然出现在意想不到的地方 |
| 情绪钩子 | 情绪未释放 | 角色看着远方，不说话 |
| 视觉钩子 | 强烈视觉画面 | 一整排人影从烟雾中走出 |

**死钩子分镜技巧**：
```
技巧1：最后一镜拉远/上升 → 让观众"看"到更大的格局
技巧2：字幕弹出 → 用文字制造信息冲击
技巧3：音乐戛然而止 → 寂静制造悬念
技巧4：画面定格/黑屏 → 强制中断，制造未完成感
```

---

### 2.6 情绪大于信息

**定义**：不灌输世界观，不解释背景，只制造情绪。

**为什么**：短剧是情绪消费，不是信息消费。观众要的是"感受"，不是"理解"。

**分镜要求**：

| 原则 | 做法 | 不做 |
|------|------|------|
| 展示不解释 | 用画面展示角色处境 | 用旁白解释角色背景 |
| 感受不理解 | 让观众感受情绪 | 让观众理解世界观 |
| 动作不对话 | 用动作传达信息 | 用对话交代剧情 |
| 道具不说明 | 用道具暗示（空鞘） | 用台词解释（"我被缴械了"） |

**信息处理策略**：
```
原则：信息通过视觉暗示传达，不通过台词/旁白解释

通用示例：
✗ 不做：旁白交代具体的时代/地点/参战方背景
✓ 做：画面展示战后废墟+俘虏被押解+军装 → 观众自己推断

✗ 不做：示例角色B说"我被缴械了，失去了武器"
✓ 做：特写示例角色B腰间的空鞘 → 观众自己看到

✗ 不做：示例角色A开口解释自己的出身与来意
✓ 做：示例角色A用一句富含身份与使命的短句 → 观众自己感受
```

### 2.7 AI全链路

**定义**：剧本→角色→分镜→视频→剪辑全链路使用AI，角色一致性是核心挑战。

**分镜要求**：
- 分镜设计必须考虑AI生成的限制（参见AI动画特殊检查项）
- 角色锚点必须完整且一致
- 锚定镜头策略必须执行
- 低成功率镜头类型必须有替代方案

**短剧AI分镜特殊策略**：

| 策略 | 说明 | 原因 |
|------|------|------|
| POV策略 | 大量使用第一人称视角 | 避免角色一致性问题（只看到手/环境） |
| 剪影策略 | 多人用剪影处理 | 避免群戏AI崩坏 |
| 单人聚焦 | 每镜聚焦1-2人 | 降低AI生成难度 |
| 道具锚定 | 用道具代替角色做视觉锚 | 道具比角色更容易保持一致 |

**通用AI策略示例**：
```
镜1：ECU示例角色A脸部 → AI高成功率（单人特写）
镜2：三连跳剪 → AI中等难度（碎片化避免连续性依赖）
镜3：POV → AI高成功率（只看到手和环境，不看到角色全身）
镜3后半：三人剪影 → AI高成功率（剪影不需细节）
镜4-6：示例角色A单人/双人 → AI中高成功率
镜7：拉远+人群 → 剪影/远景处理，AI中成功率
```

## 三、短剧分镜结构模板

### 3.1 标准7镜结构

```
镜1（3秒）· 钩子
→ 冲突/悬念/视觉冲击
→ 情绪：强烈（恐惧/震惊/好奇）

镜2（5-7秒）· 铺垫/闪回
→ 快速交代前因（碎片化/跳剪）
→ 情绪：延续或升级

镜3（8-10秒）· 反转/转机
→ 局势改变/新信息/转折点
→ 情绪：反转（绝望→希望 / 恐惧→诧异）

镜4（8-12秒）· 核心/对话
→ 最重要的对话/互动
→ 情绪：核心情感（信任/对峙/揭示）

镜5（5-6秒）· 行动/变化
→ 角色行动/场景变化
→ 情绪：过渡

镜6（5-7秒）· 追问/揭示
→ 角色追问/身份揭示
→ 情绪：紧张→释然或紧张→更深

镜7（5-6秒）· 死钩子
→ 悬念/信息冲击/视觉冲击
→ 情绪：未完成感
→ 字幕/定格/黑屏
```

### 3.2 情绪曲线

```
情绪
 ↑   ★镜1（钩子-最高）
 │   \
 │    \    ★镜3（反转）
 │     \  / \
 │      \/   \     ★镜4（核心）
 │             \  / \
 │              \/   \___ ★镜7（死钩子）
 │                    
 └──────────────────────→ 时间
   3s  7s  10s  12s  6s  7s  6s
```
