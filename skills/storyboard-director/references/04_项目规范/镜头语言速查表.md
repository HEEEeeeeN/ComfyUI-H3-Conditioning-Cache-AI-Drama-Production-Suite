## 九、轴线原则速查

```
180度规则：摄影机始终在轴线同一侧

    摄影机A（正确）    摄影机B（错误·跳轴）
         |                   |
   A -------- 轴线 -------- B

30度规则：同景别相邻镜头角度变化≥30度

合法跳轴方法：
① 摄影机运动展示越过轴线
② 插入中性镜头（正对角色）
③ 角色移动改变轴线
④ 动作引导转移注意力
```
