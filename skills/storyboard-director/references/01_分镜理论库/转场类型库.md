## 一、转场5大类型总表

| 类型 | 中文名 | 英文名 | 特点 | 适用场景 | 使用原则 |
|------|--------|--------|------|---------|---------|
| 1 | 硬切 | Cut | 直接切换，无过渡 | 连续时空、维持节奏 | 最常用，90%以上的镜头切换 |
| 2 | 淡入淡出 | Fade | 画面渐黑/渐亮 | 时间跳跃、段落分隔、章节结束 | 每集最多2-3次 |
| 3 | 叠化 | Dissolve / Cross-fade | 两个画面短暂重叠 | 时间流逝、回忆、梦境 | 情绪段落，不宜频繁 |
| 4 | 闪白 | Flash / Smash Cut | 白光闪过切到下一镜 | 冲击/惊吓/记忆碎片 | 高潮点，每集最多1-2次 |
| 5 | 匹配转场 | Match Cut | 利用视觉/动作/概念相似性衔接 | 时空转换、主题关联 | 高级技法，需精心设计 |

## 二、各类型详细说明

### 2.1 硬切 (Cut)

**定义**：一个镜头直接切换到下一个镜头，无任何过渡效果
**特点**：最简洁、最快速、最不引人注意的转场

**适用场景**：
- 同一场景内的镜头切换
- 连续时间线的叙事推进
- 维持节奏和紧张感

**使用原则**：
- 全片90%以上的转场应该是硬切
- 硬切是"隐形"的——观众不应注意到切点的存在
- 硬切的质量取决于两个镜头的衔接逻辑（见"镜头衔接逻辑"文件）

**分镜表标注**：默认转场，无需特别标注

---

### 2.2 淡入淡出 (Fade)

**定义**：
- 淡入（Fade In）：从黑屏渐变到画面
- 淡出（Fade Out）：从画面渐变到黑屏
- 淡至黑（Fade to Black）：画面逐渐变暗至全黑

**特点**：强烈的段落分隔感，暗示时间/空间的重大变化

**适用场景**：
| 场景 | 转场方式 | 效果 |
|------|---------|------|
| 开场 | 淡入 | 故事开始 |
| 章节/段落结束 | 淡出 | 一个段落的终结 |
| 重大时间跳跃 | 淡出→淡入 | 时间的断裂 |
| 角色死亡 | 淡至黑 | 生命的终结 |
| 集末结尾 | 淡出 | 本集结束 |

**使用原则**：
- 每集最多2-3次淡入淡出——频繁使用会拖慢节奏
- 淡至黑的持续时间影响情绪：短淡（1秒）= 简单分隔；长淡（3秒+）= 情绪沉淀
- 短剧（竖屏）慎用——节奏快，淡入淡出会打断观众沉浸

**分镜表标注**：在转场栏标注"Fade Out"或"Fade to Black"

**应用示例**：
- 第1集开场 → 淡入战争废墟
- 角色死亡 → 淡至黑，3秒，配低沉音效
- 集末 → 淡出，配主题音乐

---

### 2.3 叠化 (Dissolve / Cross-fade)

**定义**：一个画面逐渐消失的同时，下一个画面逐渐出现，两者短暂重叠
**特点**：柔和的过渡，暗示时间的流逝或情绪的转换

**适用场景**：
| 场景 | 效果 | 示例 |
|------|------|------|
| 时间流逝 | 数小时/数天过去 | 角色闭眼→叠化→同一位置但光线变了（白天到黄昏） |
| 回忆/闪回 | 从现在过渡到过去 | 看照片→叠化→照片中的场景变成现实 |
| 梦境 | 从现实过渡到梦境 | 角色入睡→叠化→梦境画面（更柔和/模糊） |
| 情绪转换 | 从一种情绪到另一种 | 悲伤特写→叠化→平静的全景 |

**视觉指示**：
- 叠化时画面通常带有轻微的柔和/模糊
- 回忆/闪回：配合去饱和或棕褐色调
- 梦境：配合柔光或非真实色彩

**分镜表标注**：在转场栏标注"Dissolve"或"Cross-fade to [下一镜]"

**应用示例**：
- 角色回忆过去 → 叠化从现在到回忆
- 战后时间流逝 → 叠化从战场到废墟（几个月后）

---

### 2.4 闪白 / 冲击切 (Flash / Smash Cut)

**定义**：
- 闪白：白光闪过，切到下一镜
- 冲击切：从安静/缓慢的画面突然切到激烈/响亮的画面

**特点**：极端的视觉/听觉冲击，制造惊吓或对比

**适用场景**：
| 场景 | 效果 |
|------|------|
| 突然发现/惊吓 | 安静→爆炸 |
| 记忆碎片 | 闪白→短暂的回忆画面→闪白→回到现在 |
| 梦境惊醒 | 梦境→闪白→惊醒 |
| 强对比切换 | 和平场景→突然切到战场 |

**使用原则**：
- 每集最多1-2次——过度使用会麻木
- 必须有叙事动机，不能为冲击而冲击
- 配合音效使用效果最佳（闪白配合"嗡"声/爆炸声）

**分镜表标注**：在转场栏标注"Flash to [下一镜]"或"Smash Cut to [下一镜]"

---

### 2.5 匹配转场 (Match Cut)

**定义**：利用两个镜头之间的视觉/动作/概念相似性来实现无缝转场
**特点**：最高级的转场技法，让观众"感觉不到"切换

**三种类型**：

#### 2.5.1 图形匹配 (Graphic Match)
利用相似的形状/构图/色彩：
```
镜1：角色睁大的圆形瞳孔（特写）
镜2：[MATCH CUT] 满月（圆形，同构图）
```

#### 2.5.2 动作匹配 (Action Match)
利用连续的动作：
```
镜1：角色手伸向门把手
镜2：[MATCH CUT] 手拉开另一扇门（不同地点，连续动作）
```

#### 2.5.3 概念匹配 (Conceptual Match)
利用主题/概念的关联：
```
镜1：孩子的玩具在地板上旋转
镜2：[MATCH CUT] 多年后的赌场轮盘（概念关联：命运/赌博）
```

**分镜表标注**：在转场栏标注"Match Cut - [匹配类型] - [匹配元素]"

**应用示例**：
- 角色背后大刀红绑带（特写）→ 匹配切到 → 巨型建筑上的红旗（飘动）→ 概念匹配：信念的传承
- 战场上弹壳落地（特写）→ 匹配切到 → 仪式上的勋章（同形状金属）→ 概念匹配：战争与荣誉

## 三、转场选择决策树

```
两个镜头之间是什么关系？
├── 同一场景/连续时间 → 硬切（默认）
├── 不同场景/时间跳跃
│   ├── 重大段落分隔 → 淡入淡出
│   ├── 时间流逝/回忆/梦境 → 叠化
│   └── 突然冲击/惊吓 → 闪白/冲击切
├── 有视觉/动作/概念相似性 → 匹配转场
└── 不确定 → 硬切（安全选择）
```

## 四、转场使用频率指南

| 转场类型 | 每集建议次数 | 竖屏短剧调整 |
|---------|:-----------:|:-----------:|
| 硬切 | 不限 | 不限 |
| 淡入淡出 | 2-3次 | 1次（仅开场或结尾） |
| 叠化 | 2-4次 | 0-1次（节奏太快不宜） |
| 闪白/冲击切 | 1-2次 | 0-1次 |
| 匹配转场 | 1-3次 | 0-1次（设计成本高） |

## 五、AI动画转场实现策略

| 转场类型 | AI实现方式 | 难度 |
|---------|-----------|:----:|
| 硬切 | 直接拼接两个镜头 | **最低** |
| 淡入淡出 | 后期处理（PR/剪映） | **最低** |
| 叠化 | 后期处理（PR/剪映） | **低** |
| 闪白 | 后期处理（白闪遮罩+音效） | **低** |
| 匹配转场 | 需在分镜阶段设计匹配点+后期处理 | **中高** |

**核心策略**：AI动画中转场尽量在后期处理阶段实现（剪映/PR），不在AI生成阶段做。分镜阶段只需标注转场类型和匹配元素。
