# 官方分镜方法论：六列标准镜头信息表设计法

> 本文件整合自 MiniMax 官方 `3d-animation-short-generator` Skill 的镜头表设计方法论，并适配本项目（2D 写实系短剧）。它是一套**镜头设计质量增强层**，用于提升镜头表的连续性、锚点一致性、节奏与音画配合，与现有 10 字段分镜表、分镜头需求 MD 输出格式**并存互补**，不取代下游工具链解析格式。

---

## 1. 核心思想

先故事、再资产、逐秒指令、自检守门。镜头表是"角色卡/场景卡锁定"与"单镜分镜/视频生成"之间的**强制中间产物**，不可跳过。

| 关键原则 | 说明 |
|---------|------|
| 每镜自然承接上一镜 | 通过连续性衔接列继承画面状态 |
| 每镜为下一镜铺垫 | 收尾状态为下一镜开局埋钩 |
| 每镜覆盖整镜逐秒指令 | 从 0s 到镜尾无时间空隙 |
| 逐秒指令可直接生成面板 | 避免"继续移动"这类模糊描述 |
| 空间锚点跨镜一致 | 固定地标在画面内相对位置稳定 |
| 高频逐步自检 | 任何一项不通过先修表再进入下一步 |

## 2. 六列标准镜头信息表

在角色卡与场景卡锁定后输出。表格严格按以下顺序包含六列：

| 镜头编号 & 时长 | 连续性衔接 | 参考锚点（空间+身份） | Hook 类型 | 镜头描述（每秒指令） | 音频与对白轨 |
|---|---|---|---|---|---|

### 2.1 镜头编号 & 时长

镜头号加计划时长，例如 `S03 / 6s`。

### 2.2 连续性衔接（跨镜连续主链）

说明本镜如何从上一镜的结束画面/道具位置/眼神/人物姿态/声桥/情绪状态自然承接，以及如何为下一镜开篇铺好钩子。

### 2.3 参考锚点（空间+身份）—— 四项子字段全部必填

| 子字段 | 说明 | 示例 |
|--------|------|------|
| 固定地标 | 来自场景卡的确切命名地标 + 相对画面位置 | `door-frame: 右侧 1/3`、`kitchen-island: 底部居中` |
| 人物位置（机位视角） | 每角色相对画面位置（左/中/右、上/中/下、前/中/后景）、朝向、初始姿态 | `Mia: 中央中景，面朝镜头，双手按苹果筐` |
| 退场人物状态 | 上一镜有但本镜没有的角色，记录离屏位置和原因 | `Mia — 离屏左侧，最后出现于门框旁手持苹果筐` |
| 光位基线 | 从场景卡继承的主光/补光/轮廓光方向 + 本镜调整项 | `主光：温暖顶光，补光：右侧冷反光，调整：窗光背身剪影` |

身份绑定：精确引用已批准的**角色卡名**与**场景卡名**。

### 2.4 Hook 类型（受控词表）

从受控词表挑一个短标签，用于整片 hook 分布自检：

`setup` / `visual-joke` / `reversal` / `reveal` / `callback` / `suspense` / `tender` / `chase` / `expression-beat` / `climax`

### 2.5 镜头描述（Per-Second Directives 每秒指令）

景别、镜头运动、荷兰角设计、表演风格、音效、负向提示、视频模型生成备注。强制包含 `Per-Second Directives` 子节：按秒拆解为 `0–1s`、`1–2s`、`2–3s` 等；亚秒关键节拍用 `2.0–2.5s`。每条每秒指令必须覆盖 5 个必填要素：

1. **动作 / 姿态 / 表情**（适用时含 squash-and-stretch、anticipation、overshoot、follow-through）
2. **镜头运动**（推 / 拉 / 摇 / 倾 / 手持晃动 / 锁定 / 环绕）
3. **空间位置**（人物在哪、持有什么、地标在画面哪里）
4. **音频线索**（旁白 / 对白 / 音效 / 呼吸 / 沉默，或 `silent` 表示有意静默）
5. **交接**（这一秒锁定的状态如何递给下一秒或下一镜）

> 项目适配：本项目为 2D 写实系短剧，表演不追求迪士尼式夸张弹性，但"动作/镜头/空间/音频/交接"五要素逐秒覆盖的**结构**必须保留。

### 2.6 音频与对白轨

本镜完整音频脚本，按时间顺序，独立于每秒指令：

| 字段 | 说明 |
|------|------|
| 旁白 | 旁白文本及时间范围（无旁白则省略） |
| 对白 | 台词、说话人、语气、时间范围 |
| 音效 | 关键音效，按时间锚定 |
| 表演备注 | 离屏旁白时标 `narrator-mouth-closed: true`；描述旁白期间表情路径；描述每条对白的具体眼神和身体动作变化 |

## 3. 镜头表自检门（强制）

进入分镜前必须对已批准镜头表跑硬性自检。任何一项不通过必须先修表再重跑，通过后才进入下一步。

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | Hook 密度 | 每镜都有 Hook 类型；每连续 3 镜至少 1 镜用 `reveal`/`reversal`/`callback`；开场镜和收尾镜各带强 hook |
| 2 | 单镜时长 | 任何镜头不超过 15 秒；节拍需要更长就拆镜 |
| 3 | 单镜角色数 | 任何镜头不超过 3 个重要角色（有画面动作或对白的角色） |
| 4 | 空间锚点继承 | 含 2 镜以上的同场景，下一镜固定地标与光位基线必须与上一镜一致或含明确连续性备注 |
| 5 | 每秒指令覆盖 | 从 0s 到镜尾每秒都有 Per-Second Directives，每条含 5 个必填要素，无时间空隙 |
| 6 | 跨镜连续性 | 逐行读连续性衔接列必须形成连续链；任何翻转眼神/人物位置/道具状态/光位的镜必须明确标记翻转（如 `HARD CUT — 时间跳 2h`） |

六项全过后，在镜头表顶部戳 `shot-table self-check: passed`。

## 4. 空间锚点卡（分镜字段，与 10 字段分镜表兼容）

逐镜分镜中的空间锚点卡，直接对齐半解说短剧分镜字段：

- **固定地标**：命名地标及其画面相对位置（如 `door-frame: 右侧 1/3`）
- **人物位置（机位视角）**：每个在屏角色，画面相对位置、朝向、初始姿态
- **退场人物状态**：上一镜有但本镜没有的角色，记录离屏位置和原因
- **光位基线**：从场景卡继承的主光/补光/轮廓光方向 + 本镜调整项

**连续性（对齐 Handoff 字段）**：
- `承接 S(N-1)`：一两句话交代上一镜结束状态
- `交接 S(N+1)`：一句话铺好下一镜开场

## 5. 角色卡 / 场景卡 身份锁原则

### 5.1 角色卡（身份锁）

- 角色名标注（英文和/或项目语言）
- 角色定位标注（主角、施压角色、配角等）
- 主 3/4 视角 + 正 / 侧 / 背三视图
- 表情
- 材质 / 服装 / 道具细节
- 重要道具标注
- 提示中重复的"身份锁"
- 简短视觉 ID 备注：年龄段、身材、发型、服饰色、签名道具、不可改特征

> 项目适配：项目已有角色视觉锚点规范（发型+发色+五官+体型+服装+道具、禁用代词跨镜一字不差）。官方"身份锁"原则与之一致，可强化"不可改特征"清单。

### 5.2 场景卡（连续性锚点）

场景卡只能展示环境，不出现人物/人群/剪影/手/脸/角色客串。包含：

- 主环境总览
- 关键光态：日景 / 夜景
- 情绪子空间
- 连续性地标（同场景跨镜头必须保持屏幕位置固定的物体：门框、窗、旗杆、树、邮筒等）
- 环境中的重要道具

> 项目适配：项目已有场景视觉参考。官方"连续性地标"原则用于强化跨镜空间一致。

## 6. 与项目现有流程的衔接

```
角色卡/场景卡锁定（项目风格规范）
  │
  ▼
六列标准镜头信息表（本文件方法论）
  │  逐镜含：连续性衔接 + 空间锚点 + Hook + 每秒指令 + 音频轨
  ▼
镜头表自检门（6项，全过才进入下一步）
  │
  ▼
结构化分镜表（10字段）→ 分镜头需求 MD（格式见 SKILL.md 第十二章）
  │
  ▼
下游工具链脚本 → 审阅表 → 下游工具链脚本 → 多链JSON
```

> 本项目以 **Ref2VA 全参考模式** 生产（角色定妆照 + 场景参考图驱动）。六列表中的"参考锚点（空间+身份）"直接映射到 Ref2VA 的 `<Subject N>` 定义与 `detailed_description` 的锚点描述，保证分镜到提示词的锚点一致。
