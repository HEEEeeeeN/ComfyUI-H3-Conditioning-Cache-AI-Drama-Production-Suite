# H3 提示词生成 Skill（示例项目）

> **适用范围**：从分镜导演输出的结构化分镜表出发，逐镜生成 H3 视频提示词，并合并输出为分镜头需求 MD 文件。
>
> **与 storyboard-director 的分工**：
> - 分镜导演负责**上游**："剧本 → 结构化分镜表"（镜头号、景别、机位、运镜、时长、对白、转场等）
> - 本 Skill 负责**下游**："分镜表 → H3 九分节提示词 → 分镜头需求 MD"
> - 衔接点：分镜导演输出的"结构化分镜表"→ 本 Skill 逐镜生成 H3 提示词

---

## 一、触发条件

当用户需要以下操作时触发本 Skill：

| 触发场景 | 用户意图 | 输出 |

## 三、提示词生成流程

```
Step 1: 接收分镜表
  ↓
Step 2: 确认画风与参考图槽位
  ↓
Step 3: 选择提示词模式
  ↓
Step 4: 按九分节规范逐节填充完整提示词
  ↓
Step 5: 对白格式与时长核算
  ↓
Step 6: 生成 H3 提示词要素中英双文标注
  ↓
Step 7: 生成分镜头需求 MD 文件
  ↓
Step 8: 自检
```

### Step 1：接收分镜表

接收分镜导演输出的结构化分镜表，提取每镜的：
- 镜头编号、镜头名称、时长、景别、机位角度、运镜、构图、转场
- 场景信息、角色信息、道具信息
- 对白内容（如有）、情绪/动作描述
- 空间锚点卡、Hook 类型

### Step 2：确认画风与参考图槽位

**必加载**：`07_美术与音频资源/画风锁定规范.md`（其他分线则加载 `美术风格指南.md`）

确认以下信息：
- **H3 固定画风句**：从画风锁定规范中提取（如"硬朗战场剧情风格，去饱和的灰褐色与蓝黄色调，粗黑轮廓线赛璐璐上色，阴天战场光线穿过浮尘"）
- **参考图槽位分配**：`<图片1>`=主角色定妆照、`<图片2>`=场景参考图、`<图片3>`=道具参考图、`<图片4>`+ =配角

> **画风句注入铁律**：每个镜头完整提示词的【整体风格】分节必须写入项目固定画风句，全片各镜画风句一字不差；禁止只写"电影感/写实"等泛化风格而漏掉画风句。

### Step 3：选择提示词模式

| 模式 | 适用场景 | 参考图需求 |
|------|---------|-----------|
| T2VA | 纯文本生成，无参考图 | 无 |
| I2VA | 首帧驱动 | 1张首帧图 |
| FL2VA | 首尾帧驱动 | 2张关键帧 |
| L2VA | 末帧驱动 | 1张末帧图 |
| Ref2VA | 全参考模式 | 角色+场景+道具参考图 |

本项目通常使用 **Ref2VA** 模式（角色定妆照 + 场景参考图驱动）。

### Step 4：按九分节规范逐节填充完整提示词

**必加载**：`01_提示词规范/提示词规范格式.txt`（最高优先级）+ `02_官方提示词工作流/h3_prompt_workflow.md`（识别模式与镜头语法）+ `01_提示词规范/h3_base_prompt_guide.md`（英文措辞参考，如为全参考模式则同时加载 `h3_ref_prompt_guide.md`）。

**输出骨架**：本项目「完整提示词」一律按九个分节输出，顺序固定、逐节完整填充：`【输出规格】→【参考图约束】→【整体风格】→【场景描述】→【两级时间轴】→【摄影与摄像机】→【光影】→【声音】→【约束条件】`。禁止省略分节、禁止压缩为一段话、禁止改用 H3 官方英文三字段骨架。

**本步输出的是「完整提示词」九分节全文，不是 H3 官方英文三字段。** 严格按 `提示词规范格式.txt` 的九个分节，顺序固定、逐节完整填充：

| 分节 | 填充内容 | 强制规则 |
|------|---------|---------|
| 【输出规格】 | 画幅、时长、生成模式（I2VA/Ref2VA 等） | 时长与分镜表一致 |
| 【参考图约束】 | 以 `<图片N>` 为基准，严格保持角色外貌完全一致，初始位置/姿态从参考图状态开始 | 引用 `<图片N>` 与槽位一致；逐镜写明"不得身份漂移"；**外貌锚定铁律：外貌一律由定妆照锚定，此处只声明"与 `<图片N>` 完全一致"，不在此重复罗列外貌特征** |
| 【整体风格】 | **画风句 + 风格基调** | **必须逐镜注入 H3 固定画风句**（Step 2 画风锁定确认的那句），不得省略、不得换成其他风格描述 |
| 【场景描述】 | 场景空间、物体布局、环境光线的完整描写 | 与分镜表场景一致；**只写环境与道具，不写角色外貌** |
| 【两级时间轴】 | 镜头N｜起止秒｜时长：逐段动作/光影/事件变化 + **对白锚定** | 逐秒或按关键节点分段，覆盖全时长；**对白必须按时间锚定写在此分节**（谁在哪个时间点说什么，按 Step 5 对白格式）；**只写动作/情绪/位置关系，不写身高/体型/发色/瞳色/服装/发型/伤疤等外貌** |
| 【摄影与摄像机】 | 景别、镜头运动（类型+幅度+速度）、焦点 | 按 Step 6 摄影机运动规范写 |
| 【光影】 | 主光源、环境光、特殊效果、受光区域 | 按项目色板与场景光线写；**不写角色外貌特征**（如"瞳孔清晰""下颚轮廓"） |
| 【声音】 | **仅音效**：环境音、物理动作声、非语言人声、非叙事音乐 | **禁止写入对白**；对白一律写进【两级时间轴】；本项目统一 `非叙事音乐：无` |
| 【约束条件】 | 外观一致性、物理规律、特效呈现、画幅时长等 | 与参考图约束呼应：写"严格保持 `<图片N>` 中角色外貌完全一致，不得身份漂移"；**不重复罗列外貌特征** |

> **外貌锚定铁律（最高优先级，覆盖全分节）**：人物外貌一律由参考图 `<图片N>`（定妆照）锚定，**禁止在【两级时间轴】/【场景描述】/【光影】/【约束条件】中重复人物外貌描写**（身高、体型、发色、瞳色、服装、发型、伤疤、变异特征等）。文本只写动作、情绪、景别、运镜、位置关系、对白、光影。若某外貌特征需镜头强调（如特写左眉骨伤口），用景别/构图表达（"特写敌方指挥官左眉骨伤口"），不重复完整外貌锚点。

> **指代明确铁律（最高优先级，覆盖全分节）**：所有角色指代必须使用角色名（如主角、副手、敌方指挥官），**禁止用"人影""一个人""那个人""剪影中的人"等无主指代**。剪影/剪影状态同样必须带角色名，格式为"角色名（剪影描述）"，如"主角（坦克炮塔蹲坐剪影）"、"副手（画面中央，扛机枪剪影）"。无名群演/杂兵按项目规范用身份称呼（如"我方通讯兵""敌方士兵"），禁止用"人影"笼统指代。适用于【参考图约束】/【场景描述】/【两级时间轴】/【摄影与摄像机】/【光影】/【约束条件】全部分节。

### Step 5：对白格式与时长核算

#### 5.1 对白格式（写入九分节【两级时间轴】分节）

对白写入九分节【两级时间轴】分节，**禁止写入【声音】分节**（【声音】只处理音效）。用稳定说话人 ID `(S1·男)`、`(S2·女)`（**ID 必须带性别标记**），对白用 `<d>[语言][性别] 内容</d>` 包裹（语言标签与台词原文保持剧本原样，不翻译；性别标签标注说话人性别），并按时间锚定：

```
- 1.5-3.0：通讯兵（S1·男，立正）报告：<d>[Chinese][男] 报告。敌方呼叫，要求炮击边境小镇通讯站。</d>
- 3.0-4.5：我方军官（S2·男，头也不抬，平淡）：<d>[Chinese][男] 对方指挥起我们来了？</d>
```

**S 编号是镜头局部编号（非全剧全局）**：H3 模型对跨镜头内容无记忆，每次生成调用独立。因此 S 编号**每镜独立从 S1 重新编号**，按镜头内说话人**首次出现顺序**编号为 S1、S2、S3…，单说话人镜头一律为 S1；跨镜头不沿用、不保留。

**说话人识别规则（防误判）**：判定一句话的说话人时，**只搜 `<d>` 之前的叙述文本**，台词内容里的名字不参与判定。优先级：① 有 `角色（S#` 前缀 → 直接采用；② 无前缀但有 `<d>` → 取 `<d>` 之前最后一个已知角色名；③ 都没有 → 继承本镜头上一分句的说话人。反例：敌方指挥官喊"副手"时，若用"整段文本找最后一个角色名"会误判为男（副手），正确做法是只认 `<d>` 前叙述主体"敌方指挥官"。

**性别标注规范（防止音色错配）**：模型按台词生成配音时，若说话人性别不明，会把女角色配成男声（或反之）。因此每一句对白必须同时标注说话人性别，说话人 ID 与 `<d>` 标签两处都要带：说话人 ID 用 `(S1·男)`/`(S2·女)`，`<d>` 标签用 `<d>[语言][性别] 内容</d>`。性别以角色设定为准（查 `00_项目管理与协作规范/角色性别总表.md`），两处必须一致；画外音、`[Silent]` 语气词/呼吸声同样带性别；多人同时说话用 `[群杂]` 或分别标注各说话人 ID 与性别；`<d>` 标签缺少 `[男]`/`[女]` 视为格式错误，需补全后再生成分镜。

画外音用 `says in an off-screen voiceover`（或中文"画外音"），并标注嘴唇保持闭合。本项目语言标注规则：敌方`[Korean]`、游击队`[Japanese]`、我方/主角内部`[Chinese]`；主角跨语言切换时注明 `S1 switches to [Japanese]`。

**【声音】分节只写音效**：环境音（风声/枪声/脚步声/机械声等）、物理动作声（非语言）、非叙事音乐。示例：`【声音】环境音：风声、远处枪声；非叙事音乐：无。`——不出现任何对白文本。

#### 5.2 对白时长估算（确定镜头时长）

**镜头时长必须先按对白长度核算，再叠加动作/情绪时长，取大者**，禁止不看对白直接拍脑袋定时长。估算基准（语速）：

| 语言 | 朗读语速基准 | 含标点停顿系数 |
|------|------------|---------------|
| 中文 | 约 4-5 字/秒 | ×1.2 |
| 日文 | 约 4-5 假名/秒 | ×1.2 |
| 韩文 | 约 4-5 音节/秒 | ×1.2 |
| 英文 | 约 3-4 词/秒 | ×1.2 |

**估算公式**：`对白所需秒数 = ceil(台词字符数 / 语速基准 × 1.2)`。

**镜头总时长规则**：
1. 逐句对白按公式算各自时长，各句时长相加 = 对白总时长
2. 对白总时长 + 动作/反应预留（至少 0.5-1 秒/镜） = 镜头最短时长
3. 若动作/情绪需要更长（如慢镜、沉思），以动作时长为准
4. **H3 甜点拆镜判定（硬规则）**：最终镜头时长 > 8 秒 → 必须退回分镜导演拆分；对白总时长 > 5 秒 → 必须拆成正反打/插入镜交替。**禁止把"对白总时长 + 动作预留"直接当单镜时长**
5. 最终镜头时长 = max(对白时长 + 动作预留, 动作/情绪所需时长)，并按 H3 甜点 ≤8 秒上限检查
6. 【两级时间轴】中的对白锚定时间点必须与镜头时长一致，对白结束时间不得超过镜头总时长

### Step 6：摄影机运动规范（写入九分节【摄影与摄像机】分节）

参考 H3 官方指南的三维度表达摄影机运动（运动类型 + 幅度 + 速度），写为自然动作描述：

```
The camera pushes in with small amplitude at slow speed toward the folded letter.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

可用运动类型：Zoom In/Out, Push IN/Pull Out, Pan Left/Right, Truck Left/Right, Tilt Up/Down, Pedestal Up/Down, Arc Shot, Tracking Shot, Static Shot, Shake, POV, Roll。在九分节【摄影与摄像机】分节中直接用中文或中英双语表达即可（如"景别：中景；镜头：缓慢推近，小幅度"）。

### Step 7：提示词要素中英双文标注

每个镜头的提示词要素以中英双文标注，供审阅表提取：

| 要素 | 中文 | English |
|------|------|---------|
| 镜头风格 | 电影感，实拍 | Cinematic, live-action |
| 场景 | 废弃水泥建筑内部 | Abandoned concrete building interior |
| 镜头调度 | 镜头缓慢推进，小幅度 | The camera pushes in with small amplitude at slow speed |
| 约束条件 | 角色一致性锚定 | Character consistency anchoring |

### Step 8：生成分镜头需求 MD 文件

将分镜表与 H3 提示词合并输出为**分镜头需求 MD 文件**（格式规范见第五章），包含：
- 全局信息（画幅、总时长、镜头数、风格基调、画风锚点、提示词模式）
- 逐镜头信息（基本信息 + H3 提示词要素 + 完整 H3 提示词 + 美术资产需求）
- 中英双文标注

此 MD 文件是下游 Python 工具链的输入：`shot_md_to_excel.py` 读取后生成提示词审阅表 Excel。

### Step 9：自检

**提示词自检（6项强制）**：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 九分节完整 | 每镜提示词包含全部九个分节，顺序正确，无遗漏 |
| 2 | 画风句注入 | 每镜【整体风格】分节含 H3 固定画风句，全片一致 |
| 3 | `<图片N>` 引用 | 含参考图的镜头均显式引用 `<图片N>` 槽位，引用覆盖率 = 100% |
| 4 | 对白落位 | 对白在【两级时间轴】分节，不在【声音】分节；`<d>` 标签格式正确 |
| 5 | 时长一致 | 提示词时长与分镜表一致；对白锚定时间不超镜头总时长 |
| 6 | 声音分节 | 【声音】分节仅含音效，无对白文本；非叙事音乐为"无" |
| 7 | 指代明确 | 所有角色指代用角色名，无"人影/一个人"等无主指代；剪影均带角色名（如"主角（坦克炮塔蹲坐剪影）"） |

七项全过则戳 `prompt self-check: passed`；任一不通过，返回 Step 4 修订后重跑。

**机器可读自检（输出前强制）**：生成完成后扫描全部镜头，执行以下硬性校验：

- [ ] 所有 `<d>` 均带性别标签（`<d>[语言][男女]`），缺失计数 = 0
- [ ] 所有说话人 ID 均带性别（`角色（S#·性别，状态）`），缺失计数 = 0
- [ ] 每镜 S 编号从 S1 连续递增、无跳号；单说话人镜头为 S1
- [ ] 台词内容出现他角色名时说话人仍正确（识别只搜 `<d>` 前文本）
- [ ] 所有含参考图的镜头均显式引用 `<图片N>` 槽位，引用覆盖率 = 100%
- [ ] 说话人 ID 性别与 `<d>` 性别一致
- [ ] 所有角色指代均用角色名，无"人影/一个人"等无主指代；剪影均带角色名

全部通过则戳 `machine-readable self-check: passed`；任一不达标，返回对应分节修订后重跑。

## 五、分镜头需求 MD 格式规范

### 5.1 文件命名

### 5.2 完整格式

```markdown

### A01
- **镜头名称**: 废墟猫叫
- **时长**: 5秒
- **景别**: 全景 / Wide Shot
- **机位角度**: 平视 / Eye-level
- **运镜**: 固定 / Static Shot
- **构图**: 三分法 / Rule of Thirds
- **转场**: 无（首镜）

#### H3 提示词要素
- **镜头风格 / Style**: Cinematic, live-action / 电影感，实拍
- **场景 / Scene**: Abandoned concrete building interior with dusty light beams / 废弃水泥建筑内部，浮尘光柱

#### 完整 H3 提示词
【输出规格】生成一段5秒、16:9的测试视频。图生视频模式（I2VA）。
【参考图约束】以 <图片1> 为基准，严格保持该猫咪的品种、毛色、斑纹分布、瞳色、体态比例完全一致，不得产生身份漂移或外观变异。猫咪的初始位置和姿态以 <图片1> 中呈现的为准，从该状态开始运动。
【整体风格】硬朗战场剧情风格，去饱和的灰褐色与蓝黄色调，粗黑轮廓线赛璐璐上色，阴天战场光线穿过浮尘。
【场景描述】一片废弃的水泥工厂废墟，地面散落着破碎的混凝土块、锈蚀的钢筋和积水洼。背景是坍塌的半截墙壁和框架结构，远处隐约可见灰绿色的苔藓附着在水泥表面。天空被厚重的灰白色云层覆盖，呈现典型的阴天漫射光环境。

【摄影与摄像机】景别：中景，猫咪占画面高度的约35%，保留充足的环境空间；镜头：缓慢跟随平移，从猫咪的左侧跟随至中央，速度平滑，与猫咪步行速度同步，无抖动；焦点：始终保持对猫咪的清晰对焦，背景废墟保持适度虚化但不完全模糊。
【光影】主光源：来自云层缝隙透出的自然天光，形成丁达尔光柱，色温偏暖（约3500K）；环境光：阴天漫射天光，色温偏冷（约6500K），占据画面90%区域；特殊效果：光束照射路径中需呈现悬浮微尘/水雾颗粒；猫咪受光区域：光束照射的背部区域产生暖色高光，未被照射的侧面保持阴天冷调，形成局部冷暖对比。
```
