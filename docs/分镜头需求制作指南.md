# 分镜头需求 MD 制作指南

> **目的**：帮助用户（及其 AI 助手）编写格式正确的分镜头需求 Markdown 文件，以便 `shot_md_to_excel.py` 正确解析、生成提示词审阅表，最终经 `excel_to_multi_chain_json.py` 转为 ComfyUI 多链生产 JSON。
>
> **受众**：动画制作团队的分镜导演、剧本编剧，以及辅助他们的 AI 助手。
>
> **前提**：读者无需安装分镜导演 Skill，只需遵循本指南即可产出合格文件。

## 1. 工具链总览

```
分镜导演 / AI 助手
  │
  ├──► 分镜头需求_第X集.md   ← 本指南指导产出此文件
  │
  ▼
shot_md_to_excel.py
  │
  ├──► 提示词审阅表_第X集.xlsx
  │     ├── Sheet1「提示词审阅」— 每镜一行，含场景/调度/提示词/资产/分辨率/时长
  │     ├── Sheet2「美术资产路径」— 用户在此填写角色/场景/道具的 ComfyUI input 路径
  │     └── Sheet3「说明」— 使用指引
  │
  ▼  用户审阅：调整提示词、选择分辨率(0.4/0.5)、确认时长、填写资产路径、标注修改指令
  │
excel_to_multi_chain_json.py
  │
  ├──► 多链生产 JSON（如 金止戈.json）
  │     共享 LoadImage 节点 + 每镜独立 ResolutionSelector / PrimitiveFloat / ComfyMathExpression
  │
  ▼  导入 ComfyUI 运行预编码 → 生成 .pt 缓存 → 批量生成视频
```

### 关键设计

- **MD 是唯一输入源**：`shot_md_to_excel.py` 仅从 MD 提取信息，不依赖外部数据库。
- **中英双文**：提示词要素字段使用 `中文 / English` 格式，下游工具自动提取。
- **资产去重**：多个镜头引用同一角色/场景/道具时，Excel Sheet2 自动去重，JSON 中合并为单个 LoadImage。
- **分辨率与时长的审阅权交给用户**：MD 中可预填，但最终值以 Excel 审阅表为准。

## 4. 全局信息格式

位于 `## 全局信息` 与 `## 镜头列表` 之间，每行一个字段：

```markdown
## 全局信息
- **画幅**: 16:9
- **总镜头数**: 32
- **总时长**: 156秒
- **风格基调**: Cinematic, live-action / 电影感，实拍风格
- **提示词模式**: Ref2VA
```

### 字段说明

| 字段 | 必填 | 格式 | 示例 | 说明 |
|------|------|------|------|------|
| 画幅 | 是 | `X:Y` | `16:9` 或 `9:16` | 横屏或竖屏 |
| 总镜头数 | 是 | 整数 | `32` | 本集镜头总数 |
| 总时长 | 是 | `X秒` | `156秒` | 本集总时长 |
| 风格基调 | 是 | 中英双文 | `Cinematic, live-action / 电影感，实拍风格` | 全局视觉风格 |
| 提示词模式 | 是 | 枚举值 | `Ref2VA` | 见下表 |

### 提示词模式

| 模式 | 说明 | 参考图需求 | 适用场景 |
|------|------|-----------|---------|
| T2VA | 纯文本生成 | 无 | 概念测试 |
| I2VA | 首帧驱动 | 1张首帧图 | 简单镜头 |
| FL2VA | 首尾帧驱动 | 2张关键帧 | 精确控制 |
| L2VA | 末帧驱动 | 1张末帧图 | 结尾镜头 |
| **Ref2VA** | **全参考模式** | 角色+场景+道具 | **推荐：项目标准模式** |

## 5. 镜头段落格式

每个镜头以 `### 镜头编号` 开头，包含三个子段落。

### 5.1 镜头编号规则

```
### A01
```

- 格式：大写字母 + 两位数字（如 `A01`、`B12`、`D03`）
- 字母通常表示场景线/段落：A=第一段，B=第二段，D=梦境线等
- 编号必须唯一，不可重复
- **解析器正则**：`^[A-Z]\d+`

### 5.2 基本信息

```markdown
### A01
- **镜头名称**: 废墟猫叫
- **时长**: 5秒
- **分辨率**: 0.5
- **景别**: 全景 / Wide Shot
- **机位角度**: 平视 / Eye-level
- **运镜**: 固定 / Static Shot
- **构图**: 三分法 / Rule of Thirds
- **转场**: 无（首镜）
```

| 字段 | 必填 | 格式 | 说明 |
|------|------|------|------|
| 镜头名称 | 否 | 自由文本 | 便于人工识别 |
| 时长 | 是 | `X秒`（整数或小数） | 如 `5秒`、`3.5秒`；下游 Excel 可修改 |
| 分辨率 | 否 | `0.4` 或 `0.5` | 预填值，默认 `0.5`；`0.5`=高清，`0.4`=经济 |
| 景别 | 否 | 中英双文 | 如 `特写 / Close-up` |
| 机位角度 | 否 | 中英双文 | 如 `低角度 / Low Angle` |
| 运镜 | 否 | 中英双文 | 如 `缓慢推进 / Slow Push In` |
| 构图 | 否 | 中英双文 | 如 `三分法 / Rule of Thirds` |
| 转场 | 否 | 中英双文 | 如 `硬切 / Hard Cut` |

> **注意**：字段格式必须为 `- **字段名**: 值`，冒号后有一个空格。中英双文用 ` / ` 分隔（英文在前或中文在前均可，但全文件需统一）。

### 5.3 H3 提示词要素

```markdown
#### H3 提示词要素
- **镜头风格 / Style**: Cinematic, live-action / 电影感，实拍
- **场景 / Scene**: Abandoned concrete building interior with dusty light beams / 废弃水泥建筑内部，浮尘光柱
- **镜头调度 / Camera**: The camera holds a static shot / 镜头保持固定
- **约束条件 / Constraints**: Character consistency anchoring, no axis jump / 角色一致性锚定，无跳轴
```

这四个字段会被 `shot_md_to_excel.py` 提取到 Excel 审阅表的前四列，供用户快速审阅提示词方向。

| 字段 | 必填 | 内容 | 说明 |
|------|------|------|------|
| 镜头风格 / Style | 是 | 全局视觉风格 | 如 `Cinematic, live-action` |
| 场景 / Scene | 是 | 场景环境描述 | 英文详细描述 + 中文摘要 |
| 镜头调度 / Camera | 是 | 摄影机运动描述 | 英文动作描述 + 中文摘要 |
| 约束条件 / Constraints | 是 | 生成约束 | 如一致性锚定、禁止元素等 |

### 5.4 完整 H3 提示词

```markdown
#### 完整 H3 提示词
integrated_multimodal_description: [Shot 1] Live-action, cinematic, a wide shot frames the interior of an abandoned concrete building. Dusty light beams cross the space. A soft cat call is heard from the shadows. The camera holds a static shot as the silhouette of a black cat becomes faintly visible in the corner.
overall_soundscape: A single soft cat call echoes through the empty interior, fading into silence.
non_diegetic_music: N/A
```

**格式规则**：

| 规则 | 说明 |
|------|------|
| 不使用代码块包裹 | 直接写纯文本，不要用 ` ``` ` 包裹 |
| 三核心字段顺序固定 | `integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music` |
| 每个字段独占一行 | 字段名后紧跟 `: ` 和内容 |
| 多镜用 `[Shot N]` 分隔 | 在 `integrated_multimodal_description` 中用 `[Shot 1]`、`[Shot 2]` 标注 |

详细编写规范见 [第 6 节](#6-h3-提示词编写规范)。

### 5.5 美术资产需求

```markdown
#### 美术资产需求
- **参演角色**: 黑猫
- **场景参考**: B05_场景
- **道具参考**: (无)
```

| 字段 | 必填 | 格式 | 说明 |
|------|------|------|------|
| 参演角色 | 是 | 逗号分隔的名称 | 如 `金止戈, 赤丸冢羽`；无角色填 `(无)` |
| 场景参考 | 是 | 逗号分隔的名称 | 如 `B05_场景, D03_梦境`；无填 `(无)` |
| 道具参考 | 是 | 逗号分隔的名称 | 如 `信件, 红丝带`；无填 `(无)` |

**命名规范**：
- 资产名称应与 ComfyUI input 目录中的文件名对应。
- 多个资产用英文逗号 `,` 分隔。
- 无资产时必须填 `(无)`，不可留空。
- `shot_md_to_excel.py` 会自动收集所有镜头的资产，去重后填入 Excel Sheet2。

## 6. H3 提示词编写规范

### 6.1 三核心字段

H3 提示词由三个核心字段组成，必须按顺序编写：

#### 字段 1：integrated_multimodal_description

沿时间轴描述视频内容，是提示词的主体。

**结构**：
```
[全局风格] + [场景描述] + [角色外观与位置] + [动作与反应] + [镜头运动] + [对白]
```

**编写要点**：
- 以 `[Shot N]` 开头标注镜头序号（单镜文件中 `N` 从 1 开始）
- 使用自然英文描述，而非标签堆叠
- 明确每个角色的外观特征（发型、发色、服装、体型）
- 描述摄影机运动时使用三维度表达（见 6.2）
- 对白用 `<d>[语言] 内容</d>` 包裹（见 6.3）

**示例**：
```
integrated_multimodal_description: [Shot 1] Live-action, cinematic, a wide shot frames the interior of an abandoned concrete building. Dusty light beams cross the space from gaps in the ceiling. A young woman with shoulder-length black hair, wearing a dark military uniform, stands in the center frame. She slowly raises a folded letter to eye level. The camera pushes in with small amplitude at slow speed toward the letter. She says: <d>[Chinese] 我很快就到下一站。</d>
```

#### 字段 2：overall_soundscape

用 1-4 句英文概括环境音、物理动作声、非语言人声。

**示例**：
```
overall_soundscape: A single soft cat call echoes through the empty interior, fading into silence. The faint rustle of paper can be heard as the letter is unfolded.
```

#### 字段 3：non_diegetic_music

描述非叙事性音乐。登黄项目统一使用以下内容：

```
non_diegetic_music: N/A
```

> **硬性约束**：登黄项目所有镜头的 `non_diegetic_music` 字段必须为 `N/A`，禁止任何配乐/音乐。

### 6.2 摄影机运动表达

按三维度表达：**运动类型 + 幅度 + 速度**，写为自然英文动作。

| 维度 | 可选值 | 说明 |
|------|--------|------|
| 运动类型 | Zoom In/Out, Push In/Pull Out, Pan Left/Right, Truck Left/Right, Tilt Up/Down, Pedestal Up/Down, Arc Shot, Tracking Shot, Static Shot, Shake, POV, Roll | 每镜最多一种主导运动 |
| 幅度 | small / medium / large | 运动范围 |
| 速度 | slow / medium / fast | 运动速度 |

**句式模板**：
```
The camera [运动类型] with [幅度] amplitude at [速度] speed [方向/目标].
The camera holds a static shot.  ← 固定镜头
```

**示例**：
```
The camera pushes in with small amplitude at slow speed toward the folded letter.
The camera pans right with large amplitude at fast speed, revealing the open doorway.
The camera holds a static shot as the runner exits the frame.
```

### 6.3 对白格式

使用稳定说话人 ID 和语言标签：

```
The young woman with a quiet, breathy voice (S1) says: <d>[English] I get off at the next station.</d>
```

| 元素 | 格式 | 说明 |
|------|------|------|
| 说话人 ID | `(S1)`, `(S2)`, ... | 同一文件中同一角色用同一 ID |
| 语言标签 | `[English]`, `[Chinese]`, `[Japanese]` | 对白语言 |
| 对白内容 | `<d>[语言] 内容</d>` | 用 `<d>` 标签包裹 |
| 画外音 | `says in an off-screen voiceover` | 标注嘴唇保持闭合 |

**多角色对话示例**：
```
The man with a deep voice (S1) says: <d>[Chinese] 你是谁？</d> The young woman (S2) responds: <d>[Chinese] 我叫沈天然。</d>
```

### 6.4 声音描写要点

- 描述**实际听到的声音**，不描述音乐。
- 包含：环境音、物理动作声、非语言人声（叹息、呼吸、脚步等）。
- 避免与 `integrated_multimodal_description` 中的对白重复。

## 7. 美术资产需求格式

### 7.1 资产类型

| 类型 | 字段名 | 说明 |
|------|--------|------|
| 角色 | 参演角色 | 出现在镜头中的人物，用角色定妆照驱动 |
| 场景 | 场景参考 | 镜头发生的场景环境，用场景参考图驱动 |
| 道具 | 道具参考 | 镜头中出现的可识别道具 |

### 7.2 多资产声明

```markdown
#### 美术资产需求
- **参演角色**: 金止戈, 赤丸冢羽
- **场景参考**: B05_废墟内部
- **道具参考**: 信件, 红丝带, 空刀鞘
```

- 多个资产用英文逗号 `,` 分隔。
- 名称应简洁且有辨识度，建议与 ComfyUI input 目录中的文件名前缀一致。
- 首位角色将作为 JSON 中的主角色（`ref_image_0`），第二、三位为配角（`ref_image_3`、`ref_image_4`）。

### 7.3 纯场景镜头

无角色的镜头：

```markdown
#### 美术资产需求
- **参演角色**: (无)
- **场景参考**: B05_废墟外部
- **道具参考**: (无)
```

> 解析器会将 `(无)` 视为空值，不纳入资产收集。

### 7.4 资产路径填写

资产路径在 Excel 审阅表 Sheet2 中填写，不在 MD 中声明。格式为 ComfyUI input 目录的相对路径：

```
h3_ref/角色/黑猫沈天然/沈天然黑猫定妆照.png
h3_ref/场景/B05_废墟内部.png
h3_ref/道具/红丝带.png
```

## 9. 下游工具链使用方法

### 9.1 MD → Excel

```bash
# 单文件
python tools/shot_md_to_excel.py 分镜头需求_第1集.md 提示词审阅表_第1集.xlsx

# 批量
python tools/shot_md_to_excel.py -o output/ 分镜头需求_第1集.md 分镜头需求_第2集.md

# 或使用 GUI
python tools/h3_tools_gui.py
```

**输出**：
- Sheet1「提示词审阅」：每镜一行，列含镜头编号/时长/分辨率/场景/镜头调度/约束条件/镜头风格/完整提示词/参演角色×3/场景设置×2/参演道具×3/修改指令
- Sheet2「美术资产路径」：自动收集所有资产，去重排列，用户填写 input 路径
- Sheet3「说明」：使用指引

### 9.2 用户审阅

在 Excel 中：
1. **审阅提示词**：修改场景、镜头调度、约束条件、完整提示词等列
2. **选择分辨率**：C 列下拉选择 `0.4`（经济）或 `0.5`（高清）
3. **确认时长**：B 列直接编辑数值（单位：秒）
4. **填写资产路径**：切换到 Sheet2，在 input 路径列填写 ComfyUI input 相对路径
5. **标注修改指令**：Q 列填写修改意见
6. 保存 Excel

### 9.3 Excel → JSON

```bash
# 按角色分组（默认）
python tools/excel_to_multi_chain_json.py 提示词审阅表_第1集.xlsx output/json/

# 按镜头顺序（每镜一个JSON）
python tools/excel_to_multi_chain_json.py 提示词审阅表_第1集.xlsx output/json/ --by-shot
```

**输出**：
- 按角色分组：`金止戈.json`、`沈天然.json` 等（同一角色的所有镜头在一个 JSON 中，共享 LoadImage）
- 按镜头顺序：`A01.json`、`A02.json` 等（每镜独立 JSON）
- 每个 JSON 含：共享 CLIP/VAE 节点 + 合并 LoadImage 节点 + 每镜独立 ResolutionSelector/PrimitiveFloat/ComfyMathExpression/promptLine/MiniMaxH3ReferenceToVideo/H3SaveConditioning

### 9.4 JSON → ComfyUI

1. 将生成的 JSON 导入 ComfyUI
2. 替换 LoadImage 节点中的图片路径为实际路径（如使用 GUI 的资产管理功能，路径已自动填入）
3. 运行预编码 → 生成 `.pt` 缓存文件
4. 用批量生成工作流读回 `.pt`，一键产出整集视频

## 10. 常见错误与解决方案

### 10.1 格式错误

| 错误 | 现象 | 解决方案 |
|------|------|---------|
| 镜头编号格式错误 | `### 镜头1` 或 `### scene_01` 不被解析 | 必须为 `### A01` 格式（大写字母+数字） |
| 字段格式错误 | `- 镜头名称: xxx` 不被解析 | 必须为 `- **镜头名称**: xxx`（加粗+冒号后空格） |
| H3 提示词被代码块包裹 | ` ``` ` 包裹的提示词不被解析 | 移除代码块标记，直接写纯文本 |
| 全局信息标题错误 | `## 全局设定` 不被解析 | 必须为 `## 全局信息` |
| 镜头列表标题错误 | `## 分镜表` 不被解析 | 必须为 `## 镜头列表` |
| 缺少镜头分隔线 | 相邻镜头的 H3 提示词被合并 | 每镜之间必须有 `---` |
| 资产留空而非 `(无)` | 参演角色为空时不被收集 | 无资产时填 `(无)` |

### 10.2 内容错误

| 错误 | 影响 | 解决方案 |
|------|------|---------|
| `non_diegetic_music` 不是 `N/A` | 违反项目约束 | 统一改为 `N/A` |
| 摄影机运动未用三维度表达 | 生成效果不稳定 | 补充幅度和速度描述 |
| 对白未用 `<d>` 标签 | 对白可能不被正确识别 | 用 `<d>[语言] 内容</d>` 包裹 |
| 角色描述使用代词 | 跨镜一致性无法保证 | 使用完整外观描述，禁用"她""他" |
| 资产名称不一致 | Excel Sheet2 出现重复条目 | 全文件使用统一的资产名称 |

### 10.3 解析失败排查

如果 `shot_md_to_excel.py` 报 `no shots parsed`，按以下步骤排查：

1. 检查 `## 全局信息` 和 `## 镜头列表` 标题是否精确匹配
2. 检查镜头标题是否为 `### ` + 大写字母 + 数字（如 `### A01`）
3. 检查字段是否为 `- **字段名**: 值` 格式
4. 检查 `#### 完整 H3 提示词` 标题是否精确匹配
5. 检查文件编码是否为 UTF-8（无 BOM）

- [ ] 包含 `## 镜头列表` 标题
- [ ] 每个镜头以 `### X01` 格式开头（大写字母+数字）
- [ ] 镜头之间用 `---` 分隔
- [ ] 每镜包含 `#### H3 提示词要素`，下含 Style/Scene/Camera/Constraints 四行
- [ ] 每镜包含 `#### 完整 H3 提示词`，下为三核心字段纯文本（无代码块）

- **镜头调度 / Camera**: The camera [运动描述] / [中文镜头调度]

### 12.3 关键约束速记

| 约束 | 说明 |
|------|------|
| 镜头编号 | `^[A-Z]\d+$`，如 A01、B12 |
| 字段格式 | `- **字段名**: 值`（加粗星号 + 冒号 + 空格） |
| H3 提示词 | 纯文本，不包裹代码块 |
| non_diegetic_music | 必须为 `N/A` |
| 无资产 | 填 `(无)`，不留空 |
| 多资产 | 英文逗号 `,` 分隔 |
| 中英双文 | 用 ` / ` 分隔 |
| 文件编码 | UTF-8 |
| 镜头分隔 | `---` |

### 12.4 提示词编写黄金法则

1. **integrated_multimodal_description**：自然英文，沿时间轴叙述，明确角色外观和镜头运动
2. **overall_soundscape**：1-4 句英文，只描述声音，不含音乐
3. **non_diegetic_music**：永远 `N/A`
4. **摄影机运动**：`The camera [类型] with [幅度] amplitude at [速度] speed`
5. **对白**：`<d>[语言] 内容</d>`，用稳定说话人 ID `(S1)`/`(S2)`
6. **角色描述**：完整外观（发型+发色+服装+体型），禁用代词
